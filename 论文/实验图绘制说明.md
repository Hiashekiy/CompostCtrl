# 实验图绘制说明

14幅实验图已统一为紧凑的2×2版式。标题、说明和绘图区的间距在固定画布内控制，避免原九行长图顶部留白。每幅图同时提供PNG和矢量PDF。

## 图的含义

- A/B图：主要机动轴姿态、三轴姿态误差范数、联合控制的主要轴力矩分工、该轴CMG角动量。误差图例RMSE从原始误差时序按图内机动窗口重算。
- 机制图：误差、相对初始构型的最大框架角偏移、俯仰轴角动量、俯仰轴力矩。以最大框架角偏移取代四条框架角与四条框架速率的叠加，保留10°阈值与迁移时刻。
- 浅蓝背景表示统计或观察窗口，Z零机动组不执行机动。按用户要求，所有图仅显示90–140 s，绘图前过滤140 s之后的样本，纵轴也只由图内样本确定；原始CSV与完整运行统计保持不变。图内RMSE仅统计图内机动窗口，连续任务不与完整任务RMSE混用。
- 灰色虚线的参考需求力矩是模型诊断量，气动与CMG力矩分别绘制；它不是实测外部力矩。
- 耦合任务的姿态、力矩及角动量子图显示首个机动轴，误差范数覆盖三轴；其他轴与速率、求解耗时等完整诊断仍可由原诊断函数生成。

## 代码与复现

公共样式和曲线选择：`scripts/paper_control_figures.py`。

原入口`plot_no_cmg_comparison.py:fig_scenario`和`analyze_prediction_mechanism.py:plot_group`已调用公共绘制函数；原完整图函数分别保留为`fig_scenario_diagnostics`和`plot_group_diagnostics`。

在项目根目录执行：

```powershell
python scripts/refresh_paper_figures.py
```

该命令只读取已有CSV与指标文件，不运行仿真。输出同步到项目figures目录、论文中原图4-1至图4-14路径，以及正文引用的修订目录。

气动力矩子图补充了联合组预测盒的上限、下限及浅绿色可行区间。正文每张实验图均附有独立说明，解释工况、子图意义、观察结果与统计范围。
