## What is *not* relaxed

- rotor momentum magnitude: `h0 = 50.0 N m s` per unit, `|H| <= 4 h0`
- gimbal rate: `|nu_i| <= 1.50 rad/s`
- gimbal acceleration: `|nu_k - nu_{k-1}| <= 10.0 dt` rad/s
- torque map `tau_cmg = -A(gamma) nu`, attitude dynamics, aerodynamic torque box, disturbance: unchanged.
