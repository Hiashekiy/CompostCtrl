# 实验实施与结果报告：增量式 CMG 构型路径搜索

本报告对应指导实施文件 §14 的最终交付物，覆盖全部九个阶段。所有数字来自
`experiments/cmg_incremental_search/results/`（原始时序 + 指标 + 自动生成的图），
没有任何手工修改的数据。

**一句话结论**：在 100 km、俯仰 10°/20 s 的冻结主场景下，(1) 每周期重新做有界 A\*
（C 组）**没有**带来可测收益，只增加 75 ms/周期计算量；(2) 历史路径复用 + 局部修复
（D 组）在 5 个初始构型上一致地小幅改善（姿态 RMSE −5.6 %、残差 −6.6 %、回退 −7.5 %、
`σ_min` 从 0.01 提升到 0.29），但幅度小，且部分消融表明改善来源与"未来需求引导"
关系不大（见 §5）。**不能据此宣称该方法普遍有效。**

## 2. 模型与参数（含来源与假设）

* 三轴刚体 + 四单框架金字塔 CMG + 线性气动舵面；状态 18 维，RK4，控制周期 200 ms、
  积分步 5 ms。符号与几何在阶段 1 用**独立重算**核对：`M_cmg = -A(γ)γ̇`（零外矩下惯性系
  角动量守恒到 `8.6e-15`）、`A = ∂H/∂γ`（有限差分 `1.2e-7`）、`σ_min(A(0)) = h0√(2/3)`。
* 参数溯源：惯量 `diag(1200, 8500, 9000) kg·m²` 与全部气动系数**无文献/试验出处**，
  旧项目只把质量与 `Iy` 标为 example。**因此本报告只做同一模型内的相对比较**，
  绝对量不可外推。CMG 参数（h0=50 N·m·s/台、γ̇_max=1.5 rad/s、τ_g=0.03 s、6000 rpm）
  沿用旧设计值。
* 两项旧模型没有、本实验按决策补齐并声明为假设：**框架角行程 ±90°（不绕回）**、
  **框架角加速度 10 rad/s² 作为硬约束**（plant 与分配器同时生效）。
* 未建模：转子转速动态、摩擦、气动失速/马赫效应；大气冻结在 MSIS2 单点条件
  （f107=150、ap=4、lat=45°、2024-01-01）。
* 扰动为确定性（无随机项），因此**不存在配对随机种子的需要**；公平性靠固定初始状态、
  同一控制器/分配器/执行器限制/参考轨迹/评分口径实现，配置快照逐次落盘
  （`results/metrics/*_config_snapshot.yaml`）。

## 3. 算法实现要点

| 部件 | 实现 |
|---|---|
| 基础控制器 | 四元数 PD + 陀螺前馈，`τ_req = -J(k_att e + k_rate ω_err) + ω×(Jω+H)`，A/B/C/D 共用 |
| 控制分配 | 盒约束 QP（有界最小二乘精确求解），变量 `[δ, γ̇]`，约束含舵面幅值/速率、框架角速度、**角加速度可达性**、**行程**；含气动配平常数项与**回中 + 奇异回避**参考 |
| 构型图 | 隐式局部 4 维网格（步长 10°、半径 60°、行程 ±90°），9 个动作，时间展开 `(v_i,j)→(v_l,j+1)` |
| 边评估 | 两级：执行器约束**支撑函数**筛选（~10 µs）+ 路径级**精确 QP 复核**；代价 `J_track+λ_m J_move+λ_s J_sing+λ_f J_future` |
| 有界 A\* | 双重预算（400 节点 / 60 ms），**h=0，不宣称最优性**；C 组以"保持构型"为初始解，D 组以上一周期路径为初始解 |
| D 组复用 | 平移→重锚（连不上即判失效，不硬接）→复核→局部修复（20 % 预算）→探索→受限完整重搜→只下发通过精确复核的第一步 |
| 安全回退 | 暂停迁移 → 缩小请求（1/2、1/4）→ 舵面优先；每次回退记录原因 |

## 4. 主实验：A/B/C/D × 5 个初始构型（`results/metrics/matrix_core.csv`）

主场景：100 km、俯仰 10°/20 s、起点 t=10 s、60 s 仿真、搜索步长 1.0 s、搜索预算 60 ms。

| 组 | 姿态 RMSE 均值/最坏(°) | 峰值误差 均值(°) | 残差 max 均值/最坏(N·m) | 回退 均值 | σ_min 最小 | 控制耗时 最坏(ms) | 搜索耗时 均值(ms) |
|---|---|---|---|---|---|---|---|
| A 仅舵面 | 1.582 / 1.582 | 3.220 | 71.9 / 71.9 | 231.0 | 14.18 | 25.3 | — |
| B 舵面+CMG | 0.483 / 0.640 | 1.391 | 34.6 / 48.7 | 37.4 | 0.01 | 6.2 | — |
| C 每周期有界 A\* | 0.486 / 0.654 | 1.400 | 34.8 / 49.8 | 37.6 | 0.01 | 126.4 | 74.7 |
| D 热启动+局部修复 | **0.456 / 0.595** | **1.290** | **32.3 / 45.3** | **34.6** | **0.29** | 115.5 | **35.8** |

读解：

1. **A 组明显劣于 B/C/D**（RMSE 3.3 倍、残差 2.1 倍、回退 6 倍），说明在本场景 CMG 确有价值
   ——这是 A/B 对照的结论，与本方法无关。
2**C 组 = B 组**：300 周期几乎全部返回 `warm`（"保持当前构型"仍最优），却多花 75 ms/周期。
   **每周期重新搜索在本场景没有增量价值。**
3. **D 组一致小幅优于 B/C**：5 个初始构型全部如此（RMSE −5.6 %、残差 −6.6 %、回退 −7.5 %），
   机制是"沿用并修复上一周期路径"让构型缓慢离开 ±90° 行程边缘（`σ_min` 0.01 → 0.29）。
   幅度小，且只有 5 个确定性初值，**不足以称为显著**。

## 5. 消融（`results/metrics/matrix_ablation.csv`，各 5 个初始构型）

| 消融 | RMSE 均值/最坏 | 残差 max 均值 | 回退 均值 | 搜索耗时 均值 | 结论 |
|---|---|---|---|---|---|
| C（基线） | 0.486 / 0.654 | 34.8 | 37.6 | 74.7 | — |
| 去未来需求项 `λ_f=0` | 0.485 / 0.651 | 34.8 | 37.4 | 62.7 | **无差别**（本就几乎不迁移） |
| 去未来能力项（σ_min 替代支撑函数） | 0.490 / 0.674 | 35.0 | 37.0 | 64.1 | 略差，与"能力评估有信息量"相容但幅度在噪声内 |
| 去奇异风险项 `λ_s=0` | 0.484 / 0.644 | 34.7 | 37.0 | 71.2 | 略好 → **该风险项在本场景未提供净收益** |
| 关 D 历史复用（退化为每周期重搜） | 0.448 / 0.466 | 31.4 | 35.0 | 67.4 | 边缘初值反而更好（0.466 vs 0.595）→ **复用不是一致有利** |
| 关 D 路径外探索（修复预算 100 %） | **0.434 / 0.441** | **30.3** | 33.4 | 73.9 | **全矩阵最好**：说明阶段 7 冻结的 20 % 修复预算偏小 |

**必须如实写明的三点**：

* 阶段 7 冻结的 `local_repair_budget_ratio=0.2` 事后被证明不是最优（1.0 更好）。按"正式
  对照前冻结参数、看结果前不改"的规则，本报告的主结果是**按冻结值**给出的；这一点只能
  作为下一轮独立实验的前瞻性假设，不能事后替换成更好看的配置。
* 未来的需求项与奇异项在本场景**没有可测贡献**；只有"历史复用/修复"这条路径带来了
  微小但一致的改善。这与方法声称的机理（未来需求引导构型）**不完全一致**。
* 关闭复用反而在边缘初值上更好，说明复用会带来"锁定在旧路径"的风险（§7.2 第 5 条
  所担心的正是这一点，本实验给出了它的实证）。

## 6. 可行性扫描与能力边界（`results/metrics/feasibility_scan.csv`）

A 组从 12° 起失败；B 组在 10° 时 final 0.000° 但残差 31 N·m、`σ_min` 0.07，12° 起残差
58.8 N·m。物理上，10° 机动所需峰值角动量 ≈ 139 N·m·s，已达簇总量 200 N·m·s 的七成，
框架必然走到 ±90° 行程边缘——**这是硬件边界，不是控制器调参问题**。
≥12° 的工况按 §4.2 第 6 条列为能力边界，不用于证明搜索优越。

## 7. 计算开销（指导实施文件 §11）

| 项 | 实测 |
|---|---|
| 单次节点展开 | 0.52 ms（逐层缓存 A、B_δ、配平、τ̂ 之后；之前 1.0 ms） |
| C 组每周期搜索 | 均值 74.7 ms，最坏 126.4 ms |
| D 组每周期搜索 | 均值 35.8 ms，最坏 115.5 ms |
| 单次分配 QP | 0.19 ms 均值 |
| 控制周期 | 200 ms |

最坏控制耗时 126 ms（C）/ 116 ms（D），裕量 1.6× / 1.7×。**在更复杂场景（更长窗口、更大
分支）下这个裕量不够**，§11 要求的是先减图规模/深度而不是放宽物理约束。

## 8. 失败与修补记录（都写进了代码文档串与分阶段报告）

| 缺陷 | 现象 | 处理 |
|---|---|---|
| 姿态误差符号写反 | 闭环误差指数增长到 179°，请求力矩打满 1000 N·m | 改为 `-J(k_att e + k_rate ω_err)`，文档串里锁定 |
| 分配器漏气动配平常数项 | 预测力矩系统性偏低 0.69 N·m | 常数项进 QP，A 组同状态差 0.0 |
| 回退残差按缩放后请求算 | 日志显示"残差 0"而实际缺 50 % | 残差一律相对原始请求 |
| B 组奇异锁死 | 4° 起四框架顶到 ±90°、`σ_min=0` | 回中参考 + 解析奇异梯度空转（A/B/C/D 共用） |
| 可行性语义错 | 缺口 >1 N·m 当不可行 → 252/300 周期 `no_path` | 硬可行性只看机械约束 |
| 需求预测发散 | 出现 NaN / SVD 不收敛 | `tau_cap` 截断 + 误差 >30° 冻结预测并计数 |
| 搜索超预算 | 60 ms 内完不成 → 每周期回退 | hold 种子 + 逐层缓存 |
| 重搜上限语义错 | 关复用后 297/300 周期不再搜索 | 上限只用于**连续失败** |

## 9. 局限（明确不外推）

1. 惯量与气动系数是代理参数，绝对性能无意义，只作同模型内相对比较。
2. 只有单轴俯仰机动；三轴同时机动未做（`Maneuver` 目前单轴）。
3. 只有 5 个确定性初始构型、无随机扰动，因此没有统计显著性检验；"一致小幅改善"
   只能作为趋势描述。
4. 气动为线性代理，无失速/马赫/配平随高度变化；大气冻结单点条件。
5. 搜索启发函数取 0（有界 Dijkstra），**没有全局最优性保证**；边评估的支撑函数是方向性
   上界，不保证可加可达，故仍需路径级精确复核（实测 5 % 周期被否决）。
6. 90 ms 级的最坏搜索耗时在更复杂场景下会突破 200 ms 周期，需要按 §11 先缩规模。

## 11. 结论

* **A/B 对照**：在本场景 CMG 显著优于仅舵面（RMSE 3.3 倍差距），与旧项目结论一致。
* **C（每周期有界 A\*）**：无收益，计算开销 +75 ms/周期。**方法未得到支持。**
* **D（历史复用 + 局部修复）**：5 个初值上一致小幅改善（RMSE −5.6 %、残差 −6.6 %、
  `σ_min` 0.01→0.29），但幅度小、无显著性检验，且消融显示收益来源更像"构型缓慢离开行程
  边缘"而非"未来需求引导"。**方法部分得到支持，但不能宣称普遍有效。**
* 消融同时暴露了两个负面事实：未来需求项与奇异风险项在本场景无可测贡献；
  阶段 7 冻结的修复预算比例偏小（关闭探索反而最好）。
  这些都会作为下一轮实验的前瞻性假设，而不是事后挑选的配置。
