# C1–CMG 三项诊断实验报告

**回答的问题：** CMG 让 C1 任务的姿态 RMSE 从 14.76° 恶化到 69.48°，原因分解为
（E1）持续偏置造成的净角冲量、（E2）执行机构分工、（E3）QP 失效机制 三者各占多少。

**三条独立结论（先给结论，证据在 §3–§5）：**

1. **持续偏置是决定性诱因（E1）。** 只把俯仰扰动从 `20 + 15sin` 改成 `15sin`（净角冲量
   4000 → 0 N·m·s），其它一切不动：B 组 RMSE 69.48° → **0.513°**，CMG 峰值角动量
   97.62 → **14.20 N·m·s**（预算 60），σ_min 2.76 → **37.60**，QP 回退 462 步 → **0 步**；
   A 组同时 14.76° → 0.556°，舵面饱和 25.8 % → 2.1 %。也就是说，偏置既压垮了纯舵面方案，
   又使 CMG 的角动量预算在任务时间尺度上不可持续。去掉偏置后 CMG 才首次表现出**小幅净收益**
   （0.513° vs 0.556°，−7.8 %）。
2. **不是"CMG 被过度使用"，而是"花掉动量却没换来控制力矩"（E2）。** 在俯仰轴上，
   舵面承担了几乎全部对抗力矩（份额中位数 99.9 %），而 CMG 的**中位对抗力矩≈0 N·m**
   （全程 −0.00，高空段 +0.02），只在 18–21 % 的控制步上超过 1 N·m，同时却积累了 97.6 N·m·s
   角动量。按方案 §2.3 实现的舵面优先 + 动量管理臂（B1，只改代价、约束逐位不变）只把
   RMSE 改善 3.8 %（69.48→66.87°）、峰值角动量降 5.6 %（97.62→92.13），回退步数 462→467，
   并没有把任务拉回可用区间。
3. **首次 QP 回退是数值假失败；其后的回退是两条控制器约束互相打架（E3）。**
   - t = 107.6 s（首次回退的决策状态，|H| = 30.35、σ_min = 34.73，**都在限内**）：
     冻结 QP 用独立 LP 判定**可行**（相对违反 t\* = 1.7e−16），但 OSQP 返回的解违反量
     1.49e−3 略超 1e−3 的判失败门限 → 回退是**数值精度**造成的，不是物理不可行。
   - t = 107.8 / 109.0 s：独立 LP 判定**不可行**（t\* = 0.329 / 1.534）。
     逐组归因显示瓶颈是 `momentum_box`（42 行里 32–34 行需要松弛，最大 13.4 / 62.6 N·m·s）
     与 `no_unload_thin_air`（14/14 行，最大 11.4 / 53.1 N·m·s）；**奇异约束一行都不需要松弛**。
   - 反事实：在 107.8 s，只去掉 `momentum_box` 或只去掉 `no_unload_thin_air` 都能恢复可行
     （t\*→2e−17）；到 109.0 s 只有去掉 `momentum_box` 有用（只去掉禁止卸载仍不可行，
     t\* = 1.083）。只去掉奇异约束、只放松框架速率/舵面限幅，两个时刻都仍然不可行。
     放大迭代预算（2×10⁵）、打开内部缩放、收紧容差、冷启动重解，状态仍然是 `primal infeasible`。

**三者同时成立**：任务确实存在物理上无法长期平衡的净角冲量（E1，4000 N·m·s = 预算的 67 倍），
控制器又在其中放大了问题（E3 的约束冲突 + E2 的动量空转），数值求解在最开始还给出过一次
假失败（E3 的 107.6 s）。

## 3. E3 QP 失效因果诊断

### 3.1 失效时序（按控制步重建，不按整秒）

`E3_qp_failure/event_timeline.csv` 记录 100–120 s 每一步的全部量（姿态误差、角速度、框架角与
角速度、角动量、CMG/舵面力矩、σ_min、QP 状态、迭代数、违反量、求解时间、保底标志）。

| 事件 | 时刻 [s] | 步号 | 备注 |
|---|---:|---:|---|
| 首次 QP 回退 | 107.8 | 539 | 命令由 t=107.6 s 的状态算出（标志滞后一步） |
| σ_min 首次低于下限 | 108.2 | 541 | σ_min = 8.921（下限 12.247） |
| \|H\| 首次超过预算 | 109.0 | 545 | \|H\| = 61.56（预算 60） |

**决策时刻的状态**（t=107.6 s）：\|H\| = **30.35** N·m·s（预算的一半）、σ_min = **34.73**

（0.4 s）。这直接推翻了"回退是由超预算/奇异状态触发"的直觉解释，必须重放 QP 才能定性。

### 3.3 冻结 QP 的独立可行性检查

三个时刻的完整 QP（H、g、A、lb、ub、行标签、热启动向量、状态、参考序列）冻结在
`E3_qp_failure/frozen_qp/t*.npz`。检查方法：

* 动力学行（lb = ub，252 行）作为**硬等式**，不允许松弛；另报告一版把动力学行也放进松弛集的
  结果（`lp_relax_eq_*`）。
* 主判据用**行归一化的 Chebyshev 极小极大 LP**：min t s.t. 每行相对违反 ≤ t，t = 0 ⇔ 可行。
  方案要求的 L1 弹性问题（min ‖s‖₁）也一并求解并记录；在这个条件数很大的矩阵上它有时停在
  较差顶点，所以判据取两者中更可信的一个（`lp_method` 字段写明）。

| 时刻 | 原求解器（warm） | 迭代 | 违反量 | 独立 LP：最小相对违反 t\* | 原始 QP 可行？ |
|---|---|---:|---:|---:|---|
| 107.6 s | solved | 17100 | **1.49e−3** | **1.7e−16** | **可行** |
| 107.8 s | primal infeasible | 175 | 3.2e+11 | **0.329** | **不可行** |
| 109.0 s | primal infeasible | 225 | 3.2e+11 | **1.534** | **不可行** |

**107.6 s 的解释：** 问题可行（存在满足全部行、相对违反 1e−16 的点），但 OSQP 返回的解的
无缩放违反量是 1.49e−3，略高于控制器自己的判失败门限 1e−3 → **首次回退是数值精度造成的
假失败**。同一冻结问题换求解设置（§3.5）可以拿到 1e−5 量级的解，说明不是"问题本身病态到无解"。

### 3.5 反事实放松（只诊断，不是性能结果）

| 版本 | 107.6 s t\* | 107.8 s t\* | 109.0 s t\* | 恢复可行？ |
|---|---:|---:|---:|---|
| Q0 原始 | 1.7e−16 | 0.329 | 1.534 | 107.6 可行；其余不可行 |
| Q1 放松"角动量预算组"（box+radial+thin-air） | 2.1e−17 | **2.1e−17** | **2.1e−17** | **是** |
| Q1a 只放松 `momentum_box` | — | **2.1e−17** | **2.1e−17** | **是（两个时刻都行）** |
| Q1b 只放松 `no_unload_thin_air` | — | **2.1e−17** | 1.083 | 107.8 是；109.0 **不够** |
| Q1c 只放松 `momentum_radial` | — | 0.329 | 1.534 | 否 |
| Q2 只放松奇异约束 | 1.7e−16 | 0.329 | 1.534 | 否 |
| Q3 只放松框架速率/舵面限幅 | 1.7e−16 | 0.329 | 1.534 | 否 |

**根因是 `momentum_box`（分量式角动量盒）与 `no_unload_thin_air`（薄气段禁止卸载）的死锁。**
分量盒在 |H| 接近预算时要求预测角动量不再增长（甚至回落），而薄气段规则禁止让 |H| 下降
（`H·M ≤ 0`，即 d|H|²/dt ≥ 0）。
在首次失败的 107.8 s，去掉这两条中的**任意一条**都能恢复可行——说明它们互相矛盾；
到 109.0 s，|H| 已经越过预算、矛盾加深，只去掉 `no_unload_thin_air` 已不够（t* 1.534 → 1.083，
仍不可行），只有去掉 `momentum_box` 才恢复可行。去掉径向行或奇异约束始终无效。

### 3.6 数值设置的影响（约束不变）

| 时刻 | 设置 | 状态 | 迭代 | 违反量 |
|---|---|---|---:|---:|
| 107.6 s | 项目设置（warm） | solved | 17100 | 1.49e−3 |
| 107.6 s | 收紧容差 eps=1e−8 | max iterations | 20000 | 9.7e−8 |
| 107.6 s | 冷启动 | max iterations | 20000 | 2.3e−7 |
| 107.6 s | 打开内部缩放 | max iterations | 20000 | 6.7e−4 |
| 107.8 / 109.0 s | 以上四种 + 2×10⁵ 迭代 | **primal infeasible** | 175–7050 | 3.2e+11 |

**E3 结论：** 107.6 s 的失败是**数值**（可行问题、解差 1.5e−3 被记为失败）；
107.8 s 之后是**约束构造冲突**（角动量分量盒 vs 薄气段禁止卸载），不是奇异约束、
不是框架速率限制、也不是求解器设置。冻结问题里奇异约束一次都没有成为瓶颈。

## 4. E2 执行机构分工诊断

### 4.1 B1 的机制，以及"没有放松任何约束"的证明

B1（`nearspace.cmg_priority.LTVMPCPriority`）只改两处**代价**，约束一概不动：

1. **按气动权限决定 CMG 的代价**（替代原来的"误差 > 0.5° 就让 CMG 便宜"）：
   `deficit = max_i(|M_{d,i}| − η·M_aero,max,i)`，只有"确实有瞬态误差 **且** 舵面盖不住持续需求"
   时 CMG 才便宜；当 |H| 超过软拐点（0.75 × 预算 = 45 N·m·s）后，CMG 代价随 |H| 线性升到 2 倍。
2. **显式的动量增长惩罚**：在软拐点以上对沿 Ĥ 的 CMG 力矩加二次代价
   （`r_growth·ramp·(Ĥ·M)²`，权重与 trim 代价同量级），即"不要在没必要时继续充电"。
   它不把 H 拉回零点（方案明确否定这一点），也不阻止约束要求的卸载。

预置参数（**运行前固定，未按结果调整**）：`η = 0.9`、`H_soft_frac = 0.75`、`r_growth_scale = 1.0`、
`r_growth = 0.5`。

运行前证明（`E2_actuator_allocation/check.json`）：

| 证明 | 结果 |
|---|---|
| 关闭机制时与工厂控制器的 QP 逐位相同（H,g,A,lb,ub） | ✅ 全部 True |
| 打开机制时约束矩阵与上下界仍逐位相同（A,lb,ub） | ✅ 全部 True |
| 打开机制时只有目标函数改变（软拐点上方 |H|=97.7 N·m·s 的探针） | ✅ H 相对变化 5.4e−6（Hessian 范数被状态项主导，故数值小但确实不同） |
| 解析配置差异仅限 `mpc_priority` 段 | ✅ |

### 4.3 俯仰轴分工（谁在抵消扰动）

`opposing = −M·sign(M_dist)`，正值表示在与扰动对抗；统计满足 |M_dist| > 1 N·m 的步，
取**中位数**（发散段个别饱和步的 |M_aero| 可达数千 N·m，会带偏均值）。

| 窗口 | B0 舵面份额 | B0 舵面/CMG 对抗力矩中位数 [N·m] | B1 舵面份额 | B1 中位数 |
|---|---:|---|---:|---|
| 全程 | 99.9 % | 17.52 / **−0.00** | 99.9 % | 19.20 / **0.00** |
| 高空段 90.4–149.6 s | 99.5 % | 11.84 / **+0.02** | 99.0 % | 11.63 / **+0.05** |
| 脉冲后 110–200 s | 99.6 % | 25.45 / **0.00** | 99.3 % | 38.79 / **0.03** |

CMG 的对抗力矩超过 1 N·m 的时间比例：B0 全程 21 %（高空段 18 %、脉冲后 40 %），
B1 全程 18 %（高空段 16 %）。也就是说 **CMG 大多数时候既不帮忙也不明显帮倒忙，但它在持续攒动量**。

**已知限制：** 用 0.2 s 采样的 ω 差分去闭合 `J_y·q̇ = M_aero + M_cmg + M_dist − (ω×(Jω+H))_y`
在平稳段残差就有约 30 N·m（与控制力矩同阶），发散段更大。因此上表只作**量级**证据，
不是已经闭合的力矩账。

### 4.4 判据对照（方案 §2.5）

| 判据 | 结果 |
|---|---|
| B1 明显减少 CMG 动量增长？ | 峰值降 5.6 %、终值反而升 12.6 % → **仅边际** |
| B1 改善舵面饱和与 QP 稳定性？ | 饱和 +0.9 %、回退 462→467 → **没有** |
| B1 在低空有效、高空仍发散？ | 高空段 RMSE 反而 +3.5 % → **没有改善** |
| B1 仍发散但 CMG 未到预算？ | CMG 到了预算（92.1 > 60）→ 与"物理能力不足"一致 |

**E2 结论：** 当前 MPC 的问题**不是"把持续力矩错误地交给 CMG"**——在俯仰轴上舵面本来就在
承担几乎全部对抗力矩，CMG 的中位对抗力矩≈0；问题在于 **CMG 花掉 97.6 N·m·s 动量却没有换来
控制力矩**，而这又直接导致 E3 的角动量盒/禁止卸载死锁。按方案要求、以"先说明后实现"的方式
加入舵面优先与动量管理，只能拿到 −3.8 % 的边际改善，不足以改变结论。

## 5. 三条独立结论与归因

| 层次 | 证据 | 作用 |
|---|---|---|
| **任务物理（决定性）** | 净角冲量 4000 N·m·s = 控制器预算 67 倍、硬件单轴 37 倍（E1）；去掉偏置后一切回正常（E1-C/D） | 决定"不可能长期平衡"，任何控制器都无法改变 |
| **控制器约束构造（放大因素）** | 107.8/109.0 s 冻结 QP 不可行，瓶颈是 `momentum_box` 与 `no_unload_thin_air` 的死锁；奇异约束从不binding（E3） | 使 CMG 在预算附近失去权限、并把失败锁定为连续回退 |
| **控制器代价/分工（次要）** | CMG 中位对抗力矩≈0、动量却持续累积（E2）；B1 只改善 3.8 % | 说明"分工"不是主因，但也说明现有代价函数没有惩罚"空转" |
| **数值求解** | 107.6 s 可行问题被判失败（1.49e−3 vs 1e−3 门限）（E3） | 提前 0.2 s 触发第一次回退；单独看不致命，但它把 CMG 推入保底控制器 |

### 基于证据的修改建议（下一步，不在本报告内实施）

1. **修掉首次假失败**：判失败门限应与行缩放一致（当前 1e−3 是绝对量，而行量级从 1e−2 到 5e1），
   或对返回解做一次行缩放残差复核；这一条不改任何物理约束。
2. **解开 `momentum_box` / `no_unload_thin_air` 死锁**：薄气段禁止卸载的前提是"未超预算"，
   一旦分量盒要求回落就自相矛盾；可行方向是让禁止卸载的判定与分量盒的目标一致
   （例如只在 |H| 低于预算的某个比例时才禁止），或让分量盒在超预算后改成"只允许回落"。
3. **惩罚"空转"而不是惩罚"使用"**：给 CMG 力矩加一个与扰动同向分量的代价
   （`−Ĥ·Ĥ_d·M` 之类的一次项），比单纯加大二次权重更能区分"有用的力矩"和"纯粹攒动量"。
4. 若要真正在该任务上使用 CMG，仍需 §E1 指出的三条路之一：加大动量容量、加 RCS 做动量汇、
   或把持续偏置变成已知量（前馈/配平补偿）。
