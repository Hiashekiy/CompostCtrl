# 原生迁移工程交付验收汇总

状态：当前工程主链已完成运行及重载交付检查；原方案的全部科研验收尚未完成。

重要：本轮修订定位并修复了 P0 B 组的 CMG 框架驱动接线丢失（详见 `08_closed_loop_validation.md` 的修复小节）。修复前 B 组框架角恒为零、CMG 不产生反作用力矩，控制器却在优化四个并不存在的框架速率，因此 B 组指标显著劣于 A 组。

修复后 A/B 两组的误差量级与历史 Python 实现一致；剩余差异来自真值积分格式（本模型 ode4/1 ms 对 Python 8 子步 RK4/25 ms）与扰动力矩采样方式（零阶保持对子步中点查询），尚未做逐点轨迹等价与步长收敛认证。

已验证原生 6DOF、CMG 耦合、驱动/舵机、气动力矩、公开升阻力替代模块、在线 QP/HPIPM、热启动、回退与控制分配。

默认 A/B 主模型已刷新为内嵌控制模板和未来参考的版本，保存后重载、再次仿真通过。详见 simulink/results/native_delivery/。
