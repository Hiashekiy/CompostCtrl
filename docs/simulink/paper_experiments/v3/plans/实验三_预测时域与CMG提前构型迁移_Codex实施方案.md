# 实验三：预测时域与 CMG 提前构型迁移——Codex 实施方案

## 0. 任务目标与范围

基于 `Hiashekiy/CompostCtrl` 仓库 `codex/paper-experiments` 分支的**当前 Simulink 6DOF 闭环**，重新组织论文实验三。核心问题：**当未来存在已知姿态机动时，联合 MPC 是否会在机动开始前调整四台 CMG 的框架构型和角动量；这种调整是否改善了机动方向的后续力矩能力与跟踪表现？**

沿用现有实验的可靠部分：① 5/8/12/16/23.2 s 预测时域扫描；② 已有 10° 单次俯仰任务。**删除“将 MPC 未来参考改写为当前参考”的实验在论文主证据中的地位**，改为三组真实任务对照：长时域+有机动、短时域+有机动、长时域+无机动。无机动组的物理任务确实为保持姿态，而不是偷偷修改 MPC 输入。

实施规则：只运行 MATLAB/Simulink 真正的闭环；不使用 Python 替代物理仿真；不修改正式模型 `simulink/models/NearSpace_CMG_FlightControl.slx` 与 `..._SurfaceOnly.slx`；不能修改原始 MPC 目标函数以人为制造迁移；最多 **4 轮 SQP**，0.2 s 上层周期、F20 20 ms 舵面反馈、原生舵机/CMG 动态保持现状；新结果写入**新批次目录**，不能覆盖任何旧 E3/E3_followup 数据。未经实测，不得声称“提前迁移”“性能提高”。

## 2. 三组主要对照：只改变任务和预测时域

| 组别 | 任务 | 预测时域 | 控制器是否获得完整的自身任务未来参考 | 用途 |
|---|---|---:|---|---|
| **L（长时域有机动）** | 35–40 s，俯仰增加 +10°，之后保持 | 23.2 s | 是 | 看是否提前构型迁移、机动跟踪 |
| **S（短时域有机动）** | 与 L 严格相同 | 5.0 s | 是 | 看预测视野较短时迁移起点/机动性能 |
| **Z（长时域无机动）** | 0–60 s 全程保持原参考姿态 | 23.2 s | 是（完整的零机动参考） | 排除同一飞行条件下不依赖任务的自然构型漂移 |

统一配置：`onset=35 s`、`transition=5 s`、`duration=60 s`、`profile='step'`、`cmg=true`、`method='MPC'`；L/S `amplitude=10`，Z `amplitude=0`，**所有组 `masked=false`**。原始 10° 场景来源相同，初始姿态、角速度、CMG 框架角、飞行初始条件、扰动源、控制权重/约束、求解器后端以及硬件一致。Z 也使用同一真实平动/气动环境，不是固定力矩或理想模型。

注意：`duration=60 s` 的参考轨迹到结束时会有 20 s 保持段；如现有 archived source 的未来 `tau_d` 覆盖不足，**不得偷偷把扰动清零或对 L/S/Z 采取不同外推**。三组未来扰动必须同规则，显式记录末端夹持/外推和实际有效输入时段；必要时延长共享源且进行独立验证，不要悄悄修改飞行器参数。任何超出气动/大气有效域的运行单独记 `MODEL_DOMAIN_FAIL`，不拿截断 RMSE 比较。

**因果含义必须严谨**：L vs Z 比的是“未来有无任务导致是否预置构型”；L vs S 比的是“长短预测配置导致的迁移与跟踪差异”。L/S 的网格在后段也不同，因此不能将差异完全归因于时域长度，更不能直接证明迁移对跟踪性能的独立因果贡献。

## 4. 迁移行为的定义和计算——重点

所有量优先从 Simulink 真值状态和执行器日志提取。四台框架角 `gamma_i(t)` 采用真实执行状态而非只看 MPC 指令；集群角动量按项目的原有几何配置计算：

`H(t) = sum_i h0 * [s0_i*cos(gamma_i(t)) + (g_i × s0_i)*sin(gamma_i(t))]`。

`A(gamma) = dH/dgamma`，理想反作用力矩 `tau_CMG = -A(gamma)*nu_actual`；若模型提供真实框架速率状态，**优先用真实速率**，不能优先用 `gradient(gamma,t)` 替代；只有确实没有速率日志时才用差分近似并声明偏差。框架角为展开角时要避免人为 `wrapToPi` 造成伪跳变。

### 4.1 第一层：有没有提前调整？

- 画 `H_x,H_y,H_z` 三分量，尤其 `H_y`；同时画总量 `||H||`。不把 `||H||` 下降或 `H_y` 正负直接定义为更好。
- 画四台 `gamma_i` 的真实角度，以及 `max_i |gamma_i(t)-gamma_i(0)|`；汇总机动前累计框架行程 `sum_i ∫_0^35 |nu_i(t)| dt`。
- **统一预置检测口径**：沿用上传论文 3.3 的 `max_i |gamma_i(t)-gamma_i(0)| > 10°` 首次成立为迁移阈值，要求至少连续 `0.6 s` 保持在阈值之上，以防数值抖动；以真实第一个满足时刻作为 `t_migrate`。记录“从首个采样即超过阈值”等左删失情况，不能假称精确起点。额外提供 0.5°、2° 敏感性阈值做诊断，不取代主指标。
- 以 `35 s` 为界定义提前量 `35-t_migrate`，若没有在 35 s 之前跨越主阈值则标记“未观察到提前迁移”，不能记 0 当成真实开始时刻。
- 为排除环境/扰动造成的自然漂移，比较 **`ΔH_y(t)=H_y^L(t)-H_y^Z(t)`**、**`Δγ_i(t)=γ_i^L(t)-γ_i^Z(t)`**（需确保坐标、初态相同）；同时保存 L/S/Z 绝对值，不能只展示差分。

### 4.2 第二层：迁移是否朝“更有利于未来机动”的方向？

**不能只用 `H_y` 较大来下结论。** 机动开始前（34.8–35.0 s 或最邻近完整控制周期）计算：

1. 三组的 `H_y`、`||H||`，以及真实 `gamma_i`。
2. `A(gamma)` 的最小奇异值 `sigma_min(A)` 作为构型退化诊断；不能以它一个数字就证明俯仰轴力矩更强。
3. 面向本次 +10° 俯仰机动，计算 **带符号** 的正/负俯仰轴方向的瞬时支撑力矩界（基于 `-A*nu` 与当前框架速率及加速度约束）。对于方向 `d=[0,1,0]`，分别计算 `max d'(-A nu)` 和 `max -d'(-A nu)`。须明确：这是方向投影极值，**不等于强制其他两轴力矩为零时的纯俯仰能力**。另外报告 `gamma` 当前状态、实际速率限制与下一控制步可达限制；不能只画 `sum(abs(A),2)*gdot_max` 后称其为真实可用力矩。
4. 如果可实现，再计算三轴耦合约束下，“其他两轴力矩近零”时的俯仰净力矩可达界；定义容差，使用相同的有界优化对三组评估，并报告不可行/求解状态。此项为加强项，不能为了结果好看而删去某组。
5. 比较 35–40 s 的真实 CMG 力矩、舵面实际力矩、相应饱和情况、姿态 RMSE/峰值误差，及 40–50 s 机动后稳定误差。Z 无机动，**不参加机动跟踪优劣排名**。

若 L 提前调整，但俯仰正方向可用力矩没有增加，也可能因为 MPC 规划了后续相反方向的制动/姿态稳定需求。此时如实分析具体力矩时序，不直接写“角动量优化”。

### 4.3 第三层：是否存在舵面与 CMG 的机动前力矩配合？

在 `t ∈ [10,35) s` 准备段，记录真实的 `tau_a(t)`（说明自然气动与舵面增量的区别）、`tau_CMG(t)`、净控制力矩、姿态误差、框架角速度。分析舵面与 CMG 同轴力矩反号比例，并**设定最小有效力矩阈值**，剔除接近零时的噪声反号；分别报告有效样本数量与所占时间。补偿只是支持性现象，不能仅凭反号比例证明姿态完全没有受到影响。

## 7. 必须检查的真实实验问题

1. **气动域边界**：L/S/Z 若有 `alpha` 或 `height` 有效域越界，单独保留，不把截断 RMSE 作为机动优劣；若全部越界，选经过规则公开的**共同更小机动**（如 +7.5°），三组一起重新运行，并记录为何更改；不能只调整失败组。
2. **模型外推**：审计 60 s 物理仿真与 23.2 s 未来预测窗口对应的末尾 `tau_d`、飞行状态和参考数据的边界处理。不得以 L/Z 和 S 不同的外推处理造成虚假差异。
3. **CMG 角动量与框架速度**：核对 `H` 公式、符号、惯性/机体系，确认 `tau_CMG=-A nu_actual` 和模型力矩日志一致；若有执行器惯性或实际角速度反馈差异，明确分开。
4. **迁移判据一致**：采用 10° 主阈值、持续 0.6 s，报告阈值敏感性；Z 也允许出现自然漂移，不能预设其必然为零。
5. **统计窗口一致**：准备段 [10,35)、机动段 [35,40]、机动后 [40,50]，另报 0–60 s 全程状态；完整运行前提下比较 L/S 机动误差，Z 保持误差单独报告。
6. **状态含义**：`CONTROLLER_FAIL` 区分非致命回退超阈和真正求解/仿真失败，实际求解耗时报告 mean/P95/max 与 0.2 s 周期超时比率。
7. **结果表述边界**：如果三组 H 和 gamma 几乎重合、或者角动量变化没有提高有效力矩能力，应直接报告“当前实现未观察到明确的预测性构型预置”，不能通过改变阈值、窗口或权重制造现象。
