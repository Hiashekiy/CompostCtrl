# 三任务 CMG A/B 对照（执行动态下的俯仰 ±30° 与俯仰–滚转耦合）

> 基线：`experiment/production-f20-integration` @ `a3959f7`
> 模型族：`NearSpace_CMG_FlightControl_SurfaceOnly`（A 组，仅舵面，7 状态）与 `NearSpace_CMG_FlightControl`（B 组，舵面 + 4 陀螺金字塔 CMG，11 状态）
> 试验脚本：`simulink/verify/run_ab3_cmg_task_compare.m`
> 结果：`simulink/results/ab3_cmg/20261105_ab3_legacy/`
> 全部数值来自实际 MATLAB 仿真，没有手抄；本报告不含任何"预计""预期"数值。

## 1. 三个任务与口径

| # | 任务 | 配置 | 参考（轨迹时间 90–150 s） |
|---|---|---|---|
| 1 | 正向 30° 俯仰 | `cases/S00_pitch30_{no_cmg,with_cmg}.yaml` | 俯仰 +30° hold，110–130 s |
| 2 | 反向 30° 俯仰 | `cases/S01_pitch_minus30_*.yaml` | 俯仰 −30° hold，110–130 s |
| 3 | 俯仰–滚转耦合 | `cases/S06_pitch30_roll20_*.yaml` | 俯仰 +30°、滚转 +20° hold |

- **执行动态**：模型里是真实的 1 ms 舵机（`delta_max`、`delta_dot_max`=1.047 rad/s、`tau_s`=0.05 s）与 `Aerodynamic_Surface`/`Public_surrogate` 气动力矩，MPC 仍然是 0.2 s、最多 4 轮 SQP、`analytic_full` 认证、力矩盒收缩 0。**这就是论文里的 P1（18 状态舵面真值）在本仓库的对应物**；P0（虚拟力矩舵机）只用于 `enabled && ~flight` 的另一支路，本实验未使用。
- **两臂**：同一任务下 A/B 共用**同一份参考 bank**（`cases/*_no_cmg` 与 `*_with_cmg` 只差 CMG 是否存在/使能，航迹条件逐字节相同），初值与参考完全相同，因此 A/B 差异只来自 CMG。在线控制器每拍自己重算力矩盒，bank 里的 tau 盒字段在 online 模式下被跳过，所以共用 bank 不改变任何一路的数值。
- **窗口**：图与"机动窗口 RMSE"取 90–140 s，即模型时间 **0–50 s**；全程统计取 90–150 s，即 **0–60 s**。
- 两臂的**下层都设为 `legacy`（0.2 s 开环分配）**，这样 A/B 差异不掺入生产模型新部署的 F20 20 ms 反馈。F20 版本的同一组对照可以再跑（`run_ab3_cmg_task_compare(...,'feedback_predictive',60)`），本轮未做。

## 2. 结果：机动窗口（0–50 s）姿态 RMSE

| 任务 | A：仅舵面 | B：舵面+CMG | 降幅 | 两臂共同覆盖区间 | 是否跑满 60 s |
|---|---|---|---|---|---|
| 正向 30° 俯仰 | 3.9430°（峰值 8.324°） | **0.3119°（峰值 0.722°）** | **92.1 %** | 0–50 s（两臂都到 60 s） | A 60 s / B 60 s |
| 反向 30° 俯仰 | 4.5304° | **1.0927°（峰值 5.659°）** | **75.9 %** | **0–38.20 s**（B 在 38.20 s 中断） | **A 56.89 s / B 38.20 s（都中断）** |
| 俯仰–滚转耦合 | 4.6676°（峰值 9.991°） | **0.4094°（峰值 1.034°）** | **91.2 %** | 0–50 s（两臂都到 60 s） | A 60 s / B 60 s |

全程（0–60 s，中断组只能算到各自中断时刻）：正向 A 3.8254° → B 0.3173°；耦合 A 4.6636° → B 0.4857°；反向 A 4.6436°（到 56.89 s）→ B 1.0927°（到 38.20 s）。

> 反向任务之所以用 0–38.20 s 的共同区间：B 组在 38.20 s 就撞上模型自己的 α 域断言（见第 4 节），若用 A 的 0–50 s 去比 B 的 0–38.20 s，降幅会被虚高成 77.8 %（这是先在 `ab3_comparison.csv` 里算出来的口径）。**本报告统一采用共同区间 75.9 %。**

## 4. 反向 30° 任务：两臂都触发模型域断言（必须记录的失败）

```
A 组：t = 56.892 s  Assert_alpha_domain 触发；|α| 在 0–38.2 s 内最大 25.68°，到中断时刻达 40°
B 组：t = 38.198 s  Assert_alpha_domain 触发；|α| = 40.00°（等于 polar 上限）
public_surrogate 力极曲线的 α 域：-40° … +40°
```

- 也就是说：**在这个航迹条件下，−30° 俯仰参考本身会把迎角推到验证过的力模型边界（±40°）**，模型按自身安全断言中止，与用不用 CMG 无关（B 组甚至更早撞线，因为它跟得更紧、俯仰变化更快）。
- 因此**不能**在原生模型上给出反向任务的完整 60 s A/B 结论，也**不能**复现论文里的 10.809° → 0.108°。要跑通这一任务，必须先把力模型/配平的 α 域扩到有数据支撑的范围（属于模型改造，不是控制律问题），或换一个在 ±40° 内可达的反向参考。
- 反向任务在能跑到的 0–38.2 s 内仍显示同样的趋势（4.53° → 1.09°，−75.9 %），但两臂分别出现 115 / 56 次上层安全回退，属于明显的边界工况。

## 5. 与论文数字的对照（诚实清单）

| 论文表述 | 本模型实测 | 判断 |
|---|---|---|
| 三种任务 RMSE 降幅 92.3 %–99.0 % | 正向 **92.1 %**、耦合 **91.2 %** | 与 92.3 % 同量级；**没有**达到 99 % |
| 正向窗口 RMSE 9.275° → 0.105° | 3.943° → 0.312° | 趋势一致、绝对量不同（不同降阶模型/不同参考实现） |
| 反向窗口 RMSE 10.809° → 0.108° | 4.530° → 1.093°（仅 0–38.2 s） | **不可复现**：两臂均被 α 域断言中止 |
| 耦合窗口 RMSE 8.440° → 0.652° | 4.668° → 0.409° | 降幅一致（91–92 %），绝对量不同 |
| 正向 B 组俯仰轴力矩偏差 2.57 N·m | **0.646 N·m** | 本模型的分配误差更小；"力矩盒近似已精确验证"仍不成立（见第 6 节） |
| CMG 补充力矩缓解舵面受限 | 偏角饱和 81.9 %→9.2 %，CMG 提供 ~25 N·m | **支持** |

关于"低姿态误差不等于力矩盒近似已被精确验证"：本实验同样只能给出**实测**结论——B 组三轴气动力矩合成误差仍有 0.39–0.48 N·m，俯仰单轴 0.65–0.72 N·m，窗口内最大偏差见 `ab3_comparison.csv` 的 `window_composite_err_*`。力矩盒是降阶边界，不是误差为零的证明。

## 6. 局限

1. **只在两个任务上跑到 60 s**；第三个任务被力模型 α 域挡在 38–57 s，属客观阻断，已如实保留。
2. 每格**单次**运行，未做重复实验；上层耗时在本机波动明显（正向 B 组 301 拍均值 66.0 ms、P95 119.5 ms、最大 277.2 ms、>200 ms 5 拍；A 组均值 52.1 ms、最大 578 ms 为启动拍）。
3. 两臂下层都用 `legacy` 0.2 s 分配器；生产 B 模型现在是 F20 20 ms 反馈，**本报告不代表生产配置的性能**。需要部署配置的对照时，用同一脚本传 `'feedback_predictive'` 重跑。
4. 论文来自 Python 侧 P1 模型，本报告是原生 Simulink 模型；两者不是同一实现，绝对数值不应混用。
5. CMG 力矩/角动量由记录框架角离线重算（模型内部同一套几何），不是模型直接输出端口。

## 8. 复现

```powershell
cd D:\项目\飞轮
# 1) 导出三个任务 × 两臂的参考 bank（Python + casadi）
$env:PYTHONPATH = (Join-Path (Get-Location) '.pydeps')
foreach ($c in 'S00_pitch30','S01_pitch_minus30','S06_pitch30_roll20') {
  foreach ($arm in 'no_cmg','with_cmg') {
    python simulink\py\export_online_plan_bank.py --config "configs\torque_gap_no_cmg_comparison\cases\${c}_${arm}.yaml"
    Copy-Item simulink\data\online_plan_bank.mat "tmp\banks\${c}_$($arm.Replace('no_cmg','A').Replace('with_cmg','B'))_bank.mat" -Force
  }
}
# 2) 每个任务一个 MATLAB 进程（bank 文件在 MATLAB 内被内存映射，不能在同一个进程里反复覆盖）
.\simulink\mlab.cmd "addpath('simulink'); init_paths; run_ab3_cmg_task_compare('task','20261105_ab3','S00_pitch30','legacy',60)"
.\simulink\mlab.cmd "addpath('simulink'); init_paths; run_ab3_cmg_task_compare('task','20261105_ab3','S01_pitch_minus30','legacy',60)"
.\simulink\mlab.cmd "addpath('simulink'); init_paths; run_ab3_cmg_task_compare('task','20261105_ab3','S06_pitch30_roll20','legacy',60)"
# 3) 汇总
.\simulink\mlab.cmd "addpath('simulink'); init_paths; run_ab3_cmg_task_compare('report','20261105_ab3',[],'legacy',60)"
git checkout -- simulink/data/online_plan_bank.mat   # 恢复生产参考库
```

结果文件：`ab3_comparison.csv/json`（6 个 run 的全部指标 + A/B 对比）、`ab3_common_window.csv/json`（共同区间口径 + α 诊断）、`<task>_summary.json`、`<task>_comparison.csv`、6 张 PNG。
