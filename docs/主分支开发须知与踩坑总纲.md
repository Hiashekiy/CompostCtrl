## 3. 参考库（最容易踩的坑，单独一节）

- **参考机动 = `simulink/data/online_plan_bank.mat`**，由 `simulink/py/export_online_plan_bank.py`
  从 `configs/**/cases/*.yaml` 导出；**构建时被烘焙进模型工作区**（`native_reference_bank`、
  `reference_window`），运行时不读文件。
- 导出脚本的默认 case 是 `configs/torque_gap_s08/cases/A4_descent_replay_S00_with_cmg.yaml`；
  换任务必须显式 `--config`：
  ```powershell
  $env:PYTHONPATH = (Join-Path (Get-Location) '.pydeps')
  python simulink\py\export_online_plan_bank.py --config configs\torque_gap_no_cmg_comparison\cases\S00_pitch30_with_cmg.yaml
  ```
- **仓库默认的 `online_plan_bank.mat` 是 A4 的 90 s 参考，不是两个模型当前的 S00 场景。**
  它只是"下一次构建的输入"。要重建出模型里现在这套场景，先拷存档的 bank：
  ```powershell
  Copy-Item simulink\data\scenario_banks\S00_pitch30_with_cmg_bank.mat simulink\data\online_plan_bank.mat -Force  # B
  Copy-Item simulink\data\scenario_banks\S00_pitch30_no_cmg_bank.mat   simulink\data\online_plan_bank.mat -Force  # A
  ```
- **覆盖 bank 必须先换进程**：MATLAB `load` 之后 Windows 会持有该 `.mat` 的内存映射句柄，
  同一进程内 `copyfile` 覆盖会报"请求的操作无法在使用用户映射区域打开的文件上执行"，
  重试也没用。所以"一个 bank → 一个 MATLAB 进程"。`run_ab3_cmg_task_compare` 就是按这个前提设计的。
- 时间轴口径：bank 的 `time` 就是**模型时间**（0 起）。301 点 = 60 s @0.2 s。预测时域 `dts` 合计 22.4 s，
  所以 t=60 时要用到 82.4 s 的参考 —— 这一需求由 bank 每一行**自带的 horizon** 满足，
  不要为它去延长 bank。
- 参考/初值必须两臂一致：`cases/X_no_cmg.yaml` 与 `X_with_cmg.yaml` 只差 `cmg_present/cmg_enabled`，
  对在线控制器来说 bank 里的 `tau_min/tau_max` 会被跳过（每拍自己重算），所以**两臂共用一份 bank 是安全的**，
  `docs/simulink/22` 已用同一任务验证过 A 臂结果逐位相同。

## 5. MATLAB 侧地雷（本轮逐个踩过，写死记住）

1. **函数输出个数要对得上**：`values()` 若只声明 `function data=values(ts)`，调用处写 `[~,data]=values(...)`
   就报 `MATLAB:TooManyOutputs`（本轮踩了 3 次）。helper 一律显式声明 `[t,data]`。
2. **`r.commands` 在 B 组是 7 列**（3 力矩 + 4 CMG 速率），`r.tau_actual` 是 3 列。
   算力矩误差必须 `cmd=cmd(:,1:3)`，否则 `cmd-actual` 直接尺寸不兼容。
3. **`struct([])` 不能用 `s(end+1)=entry` 追加**（"在不同结构体之间进行下标赋值"）。用
   `entries={}; entries{end+1}=entry; ... cell2mat(entries)`。
4. **`sim(si,'CaptureErrors','on')` 非法**。要 `si=si.setModelParameter('CaptureErrors','on'); r=sim(si);`
   然后 `r.ErrorMessage` 拿失败信息、`r.commands` 等仍含**中断前**的部分数据（做部分窗口统计就靠它）。
5. **`isfield(r,'delta_cmd')` 对 `Simulink.SimulationOutput` 恒为 false**（`isfield` 只认 struct）。
   要用 `try, x=r.delta_cmd; catch, end`（`report_torque_margin_feedback`/`deploy_f20_production` 里已有 `has_signal`）。
6. **索引里不能出现 `min(end,...)`**（如 `q(:,:,1:min(end,n))` → "无效的数组索引"）。先算长度再切片。
7. **`get_param(m,'FixedStep')` 返回字符串**（`.001`），直接参与算术会变成字符运算再炸 `assert`。
   一律 `str2double`。
8. **`find_system(m,'SearchDepth',0)` 找不到子系统会抛错**，不返回空。A 组没有 CMG，
   探 `Native_Plant/CMG` 必须 `try/catch`。
9. **CRLF 文件不能做多行文本替换**（本会话的工具链）→ 改 `.m` 优先用单行锚点，或整函数重写。
10. `datestr`/`now` 的弃用警告、`warning(...err.message)` 的 checkcode 提示都是噪音，别为此改逻辑。
11. 画 `|H|`、CMG 力矩等诊断量：用**记录的框架角**离线按模型同一套几何重算
    （`H=Σh0(s0 cosγ+gxs0 sinγ)`、`A(:,k)=h0(-s0 sinγ+gxs0 cosγ)`、`τ_cmg=−A·γ̇`），
    不要去改模型加端口。

## 6. Simulink / 文件系统地雷

1. **模型名 ≤63 字符**，且必须是合法 MATLAB 变量名。`NearSpace_CMG_FlightControl_SurfaceOnly_` 前缀
   已占 36 字符，`case_name` 必须 ≤24（`AB3_S06_pitch30_roll20_A` 就因为过长直接失败）。
2. **覆盖/回滚 `.slx` 前一定先 `close_system`**：模型还开着时 `copyfile` 覆盖会报
   "另一个程序正在使用此文件"（本轮第一次回滚就栽在这，已改成先关闭再恢复）。
3. 重新生成 case 模型前，如果模型因上次失败仍是 dirty，`close_system(m,0)` 会拒绝关闭；
   `build_closedloop` 已对 **case 模型**加 `set_param(m,'Dirty','off')`（正式模型不动，避免丢手工修改）。
4. **结果只写新目录**：正在运行的进程会锁住刚写过的 `.mat`/`.png`，重写历史目录必失败。
   新实验加时间戳/后缀。
5. 模型 `save` 后立刻重新 `load_system` 校验端口/连线是否持久化（生成器末尾已经这么做）。
6. `Native_Plant` 是从 `Plant_6DOF_CMG`/`Plant_6DOF_SurfaceOnly` 复制进来的子系统；
   `Aerodynamic_Surface/1`（输出）是**实测舵偏**，`/1`（输入）是舵偏指令 —— 同一个字符串两种含义，
   生成器里有注释，读代码时注意方向。

- `Environment_And_Forces/Public_surrogate/Assert_alpha_domain`：力极曲线 α 只有 **±40°**。
  **反向 30° 俯仰任务（S01）两臂都会撞这条线**（A 56.892 s、B 38.198 s），仿真中断。
  要跑通该任务只能去扩有数据支撑的 α 域或换在 ±40° 内可达的参考，**不得改断言或改极曲线凑通**。
- 舵机：`delta_max=[0.4363,0.3491,0.3491]`、`delta_dot_max=1.0472`、`tau_s=0.05`；
  `online_surface_reachability` 的闭式解与 1 ms 真值递推等价（U2 测试 600 场景最大偏差 2.8e-16 rad）。
- 禁止：`max_sqp_iterations=5`、恒定外加扰动力矩、改气动系数/CMG 配置/参考轨迹/物理步长、
  为了"通过"而放宽 `assert`。

## 8. 验收门槛（新建/改动/部署都必须过）

- 301 上层拍 / 3001 下层拍 / 60001 个 1 ms 采样；`commands.Time` 与 `tau_actual.Time` 严格同源；
- 全信号有限；**逐轴**检查 `delta_max` 与 `delta_dot_max`（不能只看三轴最大值）；
- 上下层 0 安全回退、无代数环、能关闭后从 `simulink/models` 重新打开独立仿真；
- **基线逐位复现**：`α=0` 收缩 + 同配置必须与存档 run 的 `commands/states` 差值 ≤1e-9（本轮实测 0）；
- 报告里同时给：姿态 RMSE/峰值、三轴力矩误差、饱和占比、每拍耗时分布、回退次数。
