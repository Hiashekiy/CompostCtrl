# C1 纯舵面实验复现与 CMG 统一 MPC 对比实验报告

**研究问题：** 在同一个近空间跳跃飞行任务中（C1 任务：100 km 顶点、5° 俯仰余弦脉冲 @105 s/10 s、
40 N·m 量级的持续外部扰动），增加一台真实可实现的四单元单框架 CMG、并用统一 MPC 同时优化
气动舵面与 CMG 之后，**能否降低姿态跟踪误差、缓解舵面饱和，并保持执行机构与优化器正常工作？**

**结论（先给结论，证据见正文）：**

1. 历史 C1 在**当前环境下逐位复现**：RMSE 10.4139°、峰值 31.5854°，与仓库冻结记录
   （10.4139°/31.5854°）完全一致，C1 时序逐点差值为 0。复现验收通过。
2. 在**匹配三轴模型**（同一弹道/大气/气动/参考/扰动/初值/周期/评分口径）的正式 A/B 中，
   **B 组（舵面 + CMG）比 A 组（仅舵面）差 4.7 倍**：RMSE 14.76° → 69.48°（+370.6%），
   峰值 43.48° → 178.31°，高空段 RMSE 25.17° → 70.68°，舵面饱和比例 25.8% → 45.8%，
   并且出现 462 步连续求解回退、角动量超出控制器预算 63%、σ_min 掉到奇异下限以下。
3. **失败原因定位为物理能力不足**，不是调参问题，也不是纯数值问题：
   该任务的持续扰动在 200 s 内注入 **4004 N·m·s** 角冲量，是控制器角动量预算（60 N·m·s）的
   **67 倍**、硬件单轴可用角动量（107.7 N·m·s）的 **37 倍**；CMG 在 t≈109 s 就把 60 N·m·s 打满，
   t≈108 s 起 QP 开始回退，此后它既不能继续吸收动量、也无法在稀薄气段卸载。
   一个"允许全高度卸载"的诊断臂反而更差（81.68°），证明**不是"薄气段禁止卸载"这条设计规则**
   造成的失败。
4. 因此本实验**没有**取得"CMG 降低姿态误差、缓解舵面饱和"的正向结果；本报告如实保留全部失败数据。
   仓库中已有的正面对照（冲量在预算内的工况）显示 CMG 可以小幅改善（见 §8），
   两者不矛盾，差别只在**任务总冲量与动量预算之比**。

### 2.4 关于 10.55° 与 10.41° 的差异

项目笔记中流传的 10.55° 与仓库冻结的 10.4139° 之间的差异，本次**没有**被追溯为库版本原因：

### 2.5 关于"高空段舵面饱和"的原始记录

历史 `metrics.csv` 的 `sat_fraction` 列统计的是**反作用轮**饱和
（`|h_w| ≥ 0.995 h_max`），C1 关了轮子所以该列恒为 0，它**不是**舵面饱和。
从 `baseline/historical/C1.csv` 的 `delta` 列直接统计：

| 统计 | 值 |
|---|---:|
| 升降舵峰值 | 25.00°（等于限幅） |
| \|δ\| ≥ 24.975°（判饱和）的时间比例 | **28.9 %** |
| \|δ\| ≥ 20° 的时间比例 | 29.6 % |

也就是说：历史 C1 **确实存在严重的升降舵饱和**，只是旧的指标列没有度量它。
本实验的匹配模型改用 `delta_sat_frac_all`（按 `|δ| ≥ 0.999 δ_max` 逐轴统计）作为舵面饱和指标。

## 3. 第二阶段：匹配三轴模型与公平对照

历史 `legacy/model.py` 是俯仰单轴 5 状态模型（θ, q, δ, M_rw, h_w），不能直接挂 CMG。
本实验使用仓库已有的 18 状态三轴真值模型 `nearspace/model6c.py`
（`x = [q(4), ω(3), δ(3), γ(4), γ̇(4)]`，`u = [δ_c(3), γ̇_c(4)]`），
CMG 力矩 `M_cmg = −A(γ) γ̇` 来自四单元金字塔几何，而不是一个"理想的附加力矩输入"。

### 4.2 力矩交付能力（§5.2）

用解析 box-LP 上限 `|M_axis| ≤ γ̇_max Σ_i |a·A_i|` 作为参照（俯仰方向 86.6 N·m，
对角方向 141.4 N·m）：

| 需求 [N·m] | 俯仰交付（0.3–0.6 s） | 俯仰持续（1.75–2 s） | 俯仰 σ_min 末值 | 对角交付 | 对角 σ_min 末值 |
|---:|---:|---:|---:|---:|---:|
| 5 | 0.99 | 0.99 | 40.2 | 1.00 | 40.6 |
| 10 | 1.00 | 0.99 | 38.4 | 1.00 | 40.1 |
| 20 | 1.00 | 0.99 | 30.0 | 1.00 | 40.2 |
| 40 | 0.99 | 0.00 | 0.005 | 0.99 | 19.2 |
| 61（控制器力矩盒） | 0.98 | 0.00 | 0.0006 | 0.99 | 20.0 |
| 86 | 0.805 | 0.00 | 0.0028 | 0.907 | 22.0 |
| 120 | 0.577 | 0.00 | 0.0014 | 0.604 | 21.0 |

（"交付"为实际力矩 / 需求；"持续"为保持 2 s 后的实际值）

**结论：** 短时交付能力与解析上限一致，且没有任何采样点超过当前构型的瞬时上限；
但**持续**单向力矩在 ~40 N·m 以上就会把金字塔推向奇异（σ_min 从 40.8 掉到 <0.01），
交付力矩随之坍塌。这是构型物理性质，不是数值噪声，也不是本控制器独有——
控制器的 σ_min 硬约束正是为此设置的。

| 100 km 顶点单次冷启动求解：CMG 通道确实参与（M_cmg 指令 1.06 N·m 俯仰） | PASS |

正式闭环运行带热启动，是否出现同类失败由 §5 的实测数据回答。

## 6. 第六阶段：失败机理（用数据说话）

### 6.1 时间线（B 组，取自 `cmg/c1/B/timeseries.csv`）

| t [s] | 事件 |
|---|---|
| 0–105 | |H| ≈ 0，CMG 未介入，A/B 误差几乎相同 |
| 107.8 | **第一次 QP 回退** |
| 108.2 | σ_min 首次跌破下限 12.25（实测 8.92） |
| 109.0 | |H| 首次越过控制器预算 60 N·m·s（61.56） |
| 110–150 | |H| 被钉在 62–73 N·m·s，框架角被推到奇异面附近，CMG 力矩方向权限丧失 |
| 143.4 / 171.4 | A / B 的误差峰值时刻（A 43.5° / B 178.3°） |
| 150–200 | 回退连续 462 步，|H| 上升到 97.6 N·m·s（**超出控制器预算**），滚转通道发散 |

### 6.2 为什么必然失败：冲量账

| 量 | 数值 | 与预算之比 |
|---|---:|---:|
| 任务扰动总角冲量（200 s） | **4004 N·m·s** | 66.7 × 控制器预算（60） |
| 同上 | | 37.2 × 硬件单轴可用角动量（107.7） |
| 控制器角动量预算 | 60 N·m·s | 1 × |
| CMG 集群总角动量 | 200 N·m·s | 3.3 × |
| 实测 CMG 峰值 | 97.6 N·m·s | 1.63 × 预算 |

要把一个 20 N·m 的**常值**扰动力矩用动量交换装置扛住，装置必须持续"充电"；
而 60 N·m·s 只能扛 3 s，硬件单轴 107.7 N·m·s 只能扛 5.4 s。
之后唯一的出路是把动量还给环境（气动卸载），而 90 km 以上动压只有 3–18 Pa（100 km 顶点 3.3 Pa），
舵面能提供的卸载冲量远小于扰动注入速率——所以动量只能越积越多。

### 6.3 归一化：问题不是"CMG 不好"，是"这条任务的冲量超出装置能力"

| 场景 | 任务总冲量 [N·m·s] | 与 60 N·m·s 预算之比 | CMG 结果 |
|---|---:|---:|---|
| **本实验 C1 任务（持续扰动）** | **4004** | **66.7 ×** | **RMSE +370 %（发散）** |
| 仓库 A/B 主实验 `disturbance`（120 N·m·s 脉冲） | 120 | 2.0 × | −9.4 %（0.2270°→0.2056°） |
| 仓库 A/B 主实验 `maneuver10`（10°/20 s 机动） | 139 | 2.3 × | −15.0 %（1.5476°→1.4655°） |
| 仓库设备替换实验 `cseries`（小扰动 6 自由度） | 小 | ≪1 × | 0.4706°→0.4449° |

（后三行是仓库中已冻结的既有结果，出自 `results/cmg_ab/summary.md` 与
`docs/CMG-装置替换实验-C组与T组.md`，本报告只做归一化对比，不重新解释其数据。）

同一台 CMG、同一套控制器，在冲量约 2 倍预算的任务里能改善 9–15 %；
在冲量约 67 倍预算的任务里必然发散。**决定成败的是任务冲量与动量预算之比，不是控制器调参。**

## 7. 第七阶段：诊断实验（判断"是不是设计规则害了它"）

统一 MPC 有一条设计规则：动压 `q_inf < 40 Pa` 且未超预算时**禁止卸载**
（避免把动量倒给气动舵面反而把误差倒回机体）。它是不是失败原因？

**诊断臂**（`c1_diag_unload`，同一任务、同一权重，仅把 `q_unload_min` 置 0，只跑 B 组）：

| 指标 | B（正式） | B（允许全高度卸载） |
|---|---:|---:|
| 全程 RMSE | 69.48° | **81.68°** |
| 峰值 | 178.31° | 179.65° |
| 高空段 RMSE | 70.68° | 78.48° |
| 舵面饱和比例 | 45.8 % | 45.7 % |
| CMG 峰值角动量 | 97.6 | 91.7 N·m·s |
| QP 失败步数 | 462 | 471 |
| 最坏求解时间 | 1499 ms | 1509 ms |

**结论：取消"禁止卸载"规则后结果更差，而不是更好。** 因此失败不是这条控制策略造成的；
它在 QP 层面依然不可行（471 步回退），说明约束集合本身饱和在物理边界上。

## 8. 归因：物理能力、控制器设计、数值求解各占多少

| 层 | 证据 | 判断 |
|---|---|---|
| **物理能力（决定性）** | 需要 4004 N·m·s，硬件单轴 107.7；实测 \|H\| 在 109 s 打满且卸载无门（100 km 处 q = 3.3 Pa）；σ_min 在 108 s 破下限 | **决定性限制** |
| **控制器设计（放大因素）** | 无 CMG 力矩速率惩罚项导致舵面/CMG 高频抖振（舵面每步动作量 +643 %）；薄气段禁止卸载 | 使失败提前并被放大，但不是根因（§7） |
| **数值求解（伴随现象）** | 462 步 `maximum iterations reached`；约束违反量 3.2e11；最坏 1499 ms | 是"约束不可行"的表现，不是原因；但确实使 |H| 越过预算（97.6 > 60）而无人拦截 |

**不能把三者混为一谈：** 即使把求解器做到 100 % 收敛，该任务仍然不可行
（冲量差 37–67 倍）；反过来，如果不动 C1 任务（不改冲量、不加大动量预算、不加 RCS），
任何调参都不会把 B 组变成正向结果。

## 9. 若要让 CMG 在同类任务上有用，只有三条路（都不是调参）

1. **加大角动量容量**：需要约 33 倍（2000+ N·m·s 量级），工程不现实；
2. **加 RCS / 其他动量汇**：CMG 承担瞬态、RCS 负责持续卸载（与仓库既有结论一致）；
3. **把持续扰动变成已知量**：用前馈/配平补偿把常值 20 N·m 从误差通道里拿掉，
   让 CMG 只面对瞬态部分（本仓库尚未实现，属于后续工作，本报告不声称已做到）。

## 11. 最终结论

1. **历史 C1 复现通过**：10.4139° / 31.5854°，与冻结记录逐位一致，可作为后续基准。
2. **CMG 未能在该任务上降低姿态误差或缓解舵面饱和**：RMSE 14.76° → 69.48°（+371 %），
   峰值 43.48° → 178.31°，高空段 25.17° → 70.68°，舵面饱和 25.8 % → 45.8 %，
   并伴随 462 步连续求解回退、角动量超预算 63 %、σ_min 破下限。
3. **限制来自物理能力**，其次被控制器（无 CMG 力矩速率惩罚、薄气段禁止卸载）放大，
   最后表现为数值求解失败；三者已分别给出证据（§7、§8）。
4. 该负结果**不否证 CMG 本身**：仓库中冲量约为预算 2 倍的工况下 CMG 仍有 9–15 % 改善；
   它否证的是"在 C1 这种持续大扰动任务上靠 CMG 解决姿态问题"这一设想。
5. 所有失败数据、回退记录与超限幅值均按原样保留，未做删除、重跑筛选或口径调整。
