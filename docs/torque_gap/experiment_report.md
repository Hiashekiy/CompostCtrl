### 2.1 关键建模假设（全部显式配置）

1. `τ_a` 是**合成总气动力矩**（自然 + 阻尼 + 舵面），与 `model6c` 同口径；盒的上下限由参考状态下的自然力矩 + 保守缩放的舵面可达集给出。
2. `H_nom` 在 `τ_nom` 中统一取“当前 H 冻结”（`modulation.h_nom: freeze`），所有对照臂一致。
3. 框架角行程：`CMGParams` 无行程字段，实验显式引入 **±90°**（首版假设），作为 OCP 硬约束并同时作用于 P0/P1 真值植物（P1 原有 18 状态真值**没有**行程限制，已显式补上，见 §5 失败项）。
4. 预测网格：`dt=0.2 s ×6, 0.5 s ×4, 1.0 s ×4, 2.0 s ×8`，共 22 步 / 23.2 s（C4 例外：1 s）。
5. 未使用 `σ_min` 阈值、未加动量预算硬约束（仅作诊断记录）。
6. 关闭了 legacy 的 80 N·m 瞬时扰动脉冲（会主导本次研究对象），保留物理残余扰动 `Md0 + Md_amp·sin(·)`（按动压缩放）。

## 3. 优化器验证（S2/S3）

- 决策变量 499（`X:11×23`、`U:7×22`、`V:4×23`），等式/不等式约束 364；C4 缩短时域为 125/92。
- 求解器：CasADi 3.8.2 + IPOPT，`mumps` 线性求解器、精确 Hessian、`tol=1e-6`、`max_iter=600`。实测 `ma27` 在本机返回 NaN、`limited-memory` Hessian 在同等迭代下几乎不收敛（两种模式 B0/B1 均失败），故统一使用精确 Hessian + `mumps`。
- 暖启动：上一次解按节点前移一段；冷启动用“以名义力矩前推的状态”+ 能力探针变量的精确最小二乘解初始化（这使冷启动从 400 次迭代不收敛改善为数十次收敛）。
- 每步记录：状态字符串、迭代数、墙钟、最大约束违约、是否回退，全部写入 `timeseries.csv` / `metrics.json`。
- 失败策略：未收敛 / 违约 >1e-4 / 超过 `max_cpu_s` 一律**不采用**该解；改用“上一条已验证动作（按当前气动盒、框架速率/加速度/行程重新钳位）”，无可用动作时退回 PD + 有界最小二乘缺口填补的保底控制，并记录回退原因。

## 5. 机理解释

### 5.1 提前迁移：确实发生了，但**不是** `J_cfg` 带来的

`figures/torque_gap/C1_P0_migration.png`（上图）显示：B0 与 B1 都在 **t≈90 s**（机动起点前 18–19 s）开始改变构型，
并在 **t≈99 s 就把最大框架角偏差推到 ≈90°（行程硬限位）**，然后在整个缺口窗口（110–130 s）一直贴着限位。
也就是说：本工况下“提前迁移”是由**耦合动力学 + 未来姿态要求**自然产生的——为了在 20 s 内产生 56 N·m 的
持续俯仰力矩，必须提前把 H 预置到相反方向；而准备段的气动富余（`R⁺` 在 t=90 s 约 37 N·m、t=110 s 约 6.8 N·m）
正好提供了抵消迁移反作用力矩的能力。这与方法 §3.3 的描述一致，只是**它并不需要 `E_k` 项**。

### 5.2 为什么 `J_cfg` 没有增益

1. **`E_k` 是“可行性”而不是“效率”指标**：`min_{|v_i|≤1.5}‖−A(γ)v−d‖²` 只要缺口落在瞬时能力内就是 0。
   本器件 `h0=50 N·m·s`、`γ̇_max=1.5 rad/s`，沿 −y 的瞬时能力约 86 N·m，而 10°/20° 工况的峰值缺口只有 13/34 N·m，
   因此对 **>95% 的构型 `E_k ≡ 0`**（实测 1%/5% 的构型 `E_k>0`）。目标是零，梯度就是零。
2. **真正的瓶颈是角动量与行程，不是瞬时力矩**：可达 `|H_y| ≤ 106.8 N·m·s`，30° 机动需要的动量摆幅约 115 N·m·s，
   所以构型会被推到 ±90° 限位。`E_k` 不惩罚“贴着限位”，反而因为限位处 `A(γ)` 仍可提供瞬时力矩而认为构型完全可用。
3. 因此加入 `J_cfg` 后，优化器会把一部分“为未来动量预置”的动作换成“当前瞬时能力更宽松的构型”，
   实测 B1 的准备段框架行程是 B0 的 2 倍（6.38 vs 3.16 rad）而 `pre_H` 并没有更高（119.1 vs 116.9），
   `gap_res` 更差（47.3 vs 28.9 N·m）：**迁移更乱、缺口覆盖更差**。
4. B1 的 NLP 明显更难：同样的 600 次迭代预算下，未收敛步数从 11 增到 95（回退 3.7% → 31.7%），
   单步耗时 3.3 倍。`λ_cfg=0.1` 或更大迭代预算（`--tag it1500`）都不能消除这一现象（见 §4.1 补充与 §6）。

### 5.3 “预测”本身的价值是真实可见的（C1 vs C4）

C4 只把时域从 23.2 s 缩短到 1 s（其余完全相同）：B0 的机动窗口 RMSE 从 **1.061° 恶化到 8.656°**，
峰值误差 13.5°，`pre_H` 从 116.9 掉到 0.12（完全没有预置角动量）。这说明
**“看得见未来缺口/未来力矩需求”本身带来的增益是 8 倍量级的**，只是这份增益由
`x_{k+1}=F(x_k,u_k)` 的耦合动力学 + 未来姿态目标给出，而不是由 `J_cfg` 给出。

### 5.4 三轴非对称与符号

- C2（偏航 30°）比 C1 难得多（3.11° vs 1.06°）：偏航气动权限最弱（`b Cn_dr` 通道），CMG 侧向能力虽大但 `|H|` 很快到 163 N·m·s 的边界。
- 缺口符号在 `figures/torque_gap/C1_P0_migration.png`（下图）清晰可见：112 s 出现 **+56 N·m** 正向俯仰缺口（加速段），
  125 s 出现 **−49 N·m** 负向缺口（减速段），与 `d = τ_nom − clip(τ_nom, τ_min, τ_max)` 的定义一致。

## 6. 结论与失败项

### 6.1 有效的部分

1. **模型与调制层完全可用**：43 项数值校验通过（`dH/dγ·ν=Aν` 5e-9、P0↔18 状态真值 `ω̇` 差 0、气动分解 4e-16、
   `d`/`R⁺`/`R⁻` 六类情形与符号正确、气动盒可实现性 99%@scale 0.774）。
2. **联合 OCP（B0）在 P0/P1 两套植物上都能稳定闭环**：C1 机动窗口 1.06°（P0）/1.74°（P1），
   C0 无缺口时 0.07° 且 CMG 几乎不动（`H_max` 0.40/0.23/1.45 N·m·s），验证了“无缺口不应无谓预配置”。
3. **预测时域的价值被量化**：C4（1 s 时域）8.66° vs C1（23.2 s）1.06°，8 倍量级。
4. **P1 交叉验证跑通**：舵偏角反算 + 原 18 状态真值（含 τ_s、τ_g）在同等参考/初值下闭环，
   `τ_a,desired` 与 `τ_a,actual` 逐时记录，C1 上相差 0.7–1.2°。
5. **工程失败被完整记录**：每步状态、迭代数、耗时、最大违约、回退原因都在 `timeseries.csv`。

### 6.2 失败项（不作粉饰）

1. **`J_cfg` 在本场景没有增益**：C1 +0.09°、C2 +0.10°、C3 +0.23°、C4 +0.74°、
   初始构型扫描 +0.05～0.49°、20° 强度 +0.045°；只有 C5（固定盒）−0.34° 与 10° 强度 −0.002° 略优，均在噪声量级。
   把 B1 的迭代预算放宽后它回到与 B0 相同水平（1.074° vs 1.061°），**仍无增益、且代价高 5 倍**。
   机理解释见 §5.2：`E_k` 是可行性指标，对本器件的缺口几乎恒为零。
2. **B1 的 NLP 求解质量显著退化**：回退 31.7% vs 3.7%、单步 CPU 3.3 倍、未收敛 95 步 vs 11 步。
   把迭代预算放宽到 1500 次后 B1 收敛到 1.074°（≈B0 的 1.061°），说明**“B1 更差”里相当一部分来自求解未收敛而非机制**；
   即便如此，B1 仍需 5.5 倍算力与 26% 回退，**换不来任何跟踪收益**。`λ_cfg=0.1` 不改变这一结论。
   结论：本场景下 `J_cfg` 是“净成本项”，这一点在数据上是清楚的。
3. **控制指令存在高频抖振**：`figures/torque_gap/C1_P0_B0_torque.png` 中 `τ_cmg` 在 ±10～100 N·m 间快速切换，
   `τ_a` 在上下界间 bang-bang 跳变。原因是每 0.2 s 重解一次、只执行第一段，而 `R_Δν`、`R_Δτ` 权重相对姿态项过小，
   优化解在等价面内漂移。**这会削弱 B0/B1 差异的显著性判断**，属需要修复的实现问题。
4. **P1 的原有 18 状态真值没有框架行程限制**：第一版 P1 直接发散（|γ| 跑到 −13.5 rad，NLP 因初值越界全部不可行，
   回退 83%、RMSE 47°）。已在 runner 中补上 ±90° 硬限位（与 P0 一致）后恢复正常（1.74°）。
   这说明**旧真值模型缺一个真实硬件限制**，不是算法问题。
5. **`τ_a` 变化率约束未启用**：`torque_gap.tau_rate_limit: null`，因为没有可信的 N·m/s 折算；任务书要求的这一消融项本轮**未做**。
6. **B3（构型参考软引导）未做**：按任务书“主项消融验证有效后再加”，本轮主项未显示增益，故不实施。
7. **实时性不成立**：B0 单步 0.44 s（P95 1.75 s）远大于 0.2 s 控制周期；本报告不宣称实时能力。

### 6.3 下一轮最小改进建议（需用户批准后再做）

1. **把“能力”从瞬时可行改为可积/带代价**：用 `min_{|v|≤ν_max} ‖A(γ)v + d‖² + ρ‖v‖₁`（或直接对 `d` 的持续时长加权），
   让 `E_k` 能区分“贴着 ±90° 限位也能瞬时出力”的构型；这直接对应本轮失败根因。
2. **修控制抖振**：提高 `R_Δν/R_Δτ`、加入 move-blocking（控制分段常值）或对上一周期解做一致性惩罚，
   再做一次 B0/B1 对比，才能把“机制效应”与“求解噪声”分开。
3. **给 B1 一个公平的求解基线**：例如 B1 用 2 次 SQP 热启动（先解 λ=0，再解 λ>0），并固定 `max_iter`/预算，
   使两臂的回退率可比。
4. **P1 侧补 `τ_a` 分配残差与舵偏角饱和统计**为独立指标列，量化“抽象力矩可实现性”的损失。
5. 若仍要保留 `J_cfg`，建议先做**离线能力图**（把 `E_k(γ, d)` 预计算成表），确认在目标缺口下该函数确实能区分构型，
   再进入闭环——本轮的数据（`feasibility.md`）表明在 30° 以下它区分不出来。
