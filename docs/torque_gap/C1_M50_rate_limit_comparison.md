## 2. 结论

1. **换成 M50 的真实限制后，这个机动仍然完成得很好**：窗口 RMSE 0.309°（原 0.318°，差 -2.9%），峰值误差 0.648°（原 0.650°）。
2. **两个新限制都真的被用满了**：实测峰值 |ν| = 1.000 rad/s（上限 1.0）、峰值每步 |Δν| = 0.600 rad/s（上限 0.6）。也就是说这不是“限制没起作用”的假对比。
3. **机动后更平稳、尾部明显更干净**：130–146 s 最大误差 0.452°（M50）vs 0.375°（原），都在 0.5° 以内；尾部（>146 s）3.018° vs 9.834°。原因很可能是更低的速率/加速度上限压掉了原来那部分“高频换构型”的抖振（对比两条 τ_cmg 与 ν 曲线可见：原假设在 135–145 s 有尖峰）。
4. **瓶颈仍是角动量，不是速率**：两臂 |H| 峰值 158.6 / 162.3 N·m·s，已达几何可达 163.2 的 97%/99%，俯仰轴边界 157.7 N·m·s；M50 一臂转得更多（0.79 → 1.26 圈）以换取同样的角动量摆幅。
5. **缺口覆盖反而更好**：机动期 ‖τ_cmg−d‖ 均值 12.2 → 8.0 N·m。因为速率上限更低时，优化器更倾向于把角动量用在“有用方向”，而不是快速来回换构型。

## 3. 需要注意

- 其余权重保持原样（`nu_scale = 1.5` 只是代价归一化，不随上限改变），所以这是一次纯粹的“只改限制”的对比。
- 结论仅对 C1（30°/20 s 俯仰）成立；更激烈的机动或需要更高关节速度时会不同，建议下一轮用 M50 限制扫 C2（偏航）/C3（多轴）。
- P0 仍是虚拟力矩植物；真实舵面（P1）与本轮改动无关，未重跑。
