> **本文件只包含最终加速配置（HPIPM 实时迭代 RTI + 信赖域）下的 11 组对照结果。**
> 早期基于 IPOPT 的基线臂已按要求从数据集中移除（仍可从 git 历史取回）。
> 数据：`results/torque_gap_no_cmg_comparison_rti2/`；图：`figures/torque_gap_no_cmg_comparison/{P0_rti2,P1_rti2}/`。

11 组 = P0 的 S00–S06（7 组）+ S07 连续机动（1 组）+ P1 真实舵面的 S00/S01/S06（3 组），
每组都含 A（无 CMG）与 B（舵面+CMG）两个臂。

## 2. 两组系统的定义

| | A 无 CMG | B 舵面 + CMG |
|---|---|---|
| 状态 | `[q(4), ω(3)]` = 7 | `[q(4), ω(3), γ(4)]` = 11 |
| 控制 | `[τa(3)]` = 3 | `[τa(3), ν(4)]` = 7 |
| 刚体动力学 | `Jω̇ = τa + τd − ω×Jω` | `Jω̇ = τa + τcmg + τd − ω×(Jω + H(γ))` |
| CMG 状态/诊断量 | 不存在（图与表标“不适用”） | 全部记录 |

A 组不是“把 ν 冻结为零”：其优化问题里没有 γ、ν、框架行程界与框架速率约束，动态方程里没有 `A(γ)ν` 与 `H(γ)`（见 `no_cmg_vs_cmg_code_audit.md` §3）。
CMG 力矩列的符号约定为**机体所受**力矩 `τcmg = −A(γ)ν`，所以 `τa + τcmg` 应当逼近参考需求 `τnom`（S00/B 实测相关系数 +0.982）。

## 3. 求解器配置（最终加速手段）

| 项 | 取值 |
|---|---|
| 算法 | HPIPM 实时迭代（RTI）：每步 Gauss-Newton SQP，最多 12 个 QP |
| 线性化 | CasADi 解析雅可比，RK4 映射与真值模型一致到 1e-12 |
| Hessian | Gauss-Newton（姿态/角速度误差的 `JᵀJ`），不求动力学二阶导 |
| 稳定性 | 每级硬信赖域 `\|δγ\| ≤ 0.5 rad`、`\|δω\| ≤ 1 rad/s` |
| 全局化 | 非线性目标上的回溯线搜索（1, 1/2, 1/4, 1/8） |
| 终止 | QP 步长 < 1e-4 时提前退出 |
| 约束 | 逐级气动力矩盒、`\|ν\| ≤ γ̇max`；`γ̈` 耦合由信赖域 + 执行侧限幅表达 |
| 执行侧限幅 | CMG 力矩变化率 `\|dτ_cmg/dt\| ≤ 80 N·m/s`（=16 N·m/步） |

单步耗时（本轮干净环境实测）：A 组均值 57 ms / P95 101 ms，B 组均值 106 ms / P95 130 ms。

## 3.1 窗口末段的 CMG 抖动与已试过的两个对策

S00/B 在 146–150 s 出现明显抖动（图 4/6/7 幅）：CMG 输出 4.6 → 59.8 → 97.1 N·m，而参考需求只有 0.43–0.55 N·m；`|H|` 在 3 s 内 42 → 83 → 146 → 155 N·m·s，框架速率饱和 32–75%，姿态误差从 0.28° 涨到 3.77°。

**不是能力不足**：按真实 `A(γ)`、`|ν| ≤ γ̇max` 计算的沿 +y 瞬时能力为 39–126 N·m，而需要补的只有约 9.6 N·m（末段动压涨 4.8 倍，气动能力盒上界被拖到负值，舵面顶死在上界）。真正的机制是**控制律在末段过度驱动**：QP 里速率误差权重（`2/ω_scale² ≈ 5000`）远大于力矩正则（`2r_ν/ν_scale² ≈ 0.04`），微小的速率误差就换来上百牛·米，逐步累积成极限环。

试过并**否决**的两个代价整形方案（S00/B 实测，机动窗 / 末段 RMSE）：

| 方案 | 机动窗 | 末段(post) | 结论 |
|---|---:|---:|---|
| 无（基线） | 0.0851 | 0.744 | — |
| 角动量水平惩罚 ρ=0.03…1.0（`mom_penalty`，软阈值 0.7·4h₀） | 0.10–0.14 | 1.01–1.45 | 变差；峰值 |H| 出现在机动预置期，压它等于拿跟踪换储备 |
| 速率平滑 `r_dnu` 1→100、`r_nu` 1 | 0.12–0.82 | 0.73–1.11 | 变差或持平 |
| **执行侧力矩变化率限幅 80 N·m/s（采用）** | **0.0854** | **0.508** | 机动窗不变，末段 −32% |

采用限幅后：S00 末段 0.744→0.508、S03 16.25→14.43、P1-S06 0.365→0.248，机动窗变化在 ±0.06° 以内（S01 反而更好 0.132→0.106，P1-S06 略差 0.652→0.709）。该限幅写在 `configs/.../base.yaml` 的 `torque_gap.cmg_slew_max`，对 A/B 两组同时生效（A 组无 CMG，不受影响），配置审计仍为 0 违规。

## 10. 判读（按指导书 §13 的规则）

1. **B 组 RMSE 更低** → CMG 辅助改善了姿态跟踪，改善幅度 −77.9% … −100.0%；
2. **B 组舵面负担更高** 不是坏事：A 组被气动能力盒限制（贴边 0.17–0.73）而无法执行机动，B 组真正在出力；
3. **机制证据成立**：提前 18–19 s 迁移、`Hy` 随俯仰方向反号；
4. **能力边界如实报告**：S03/S05 存在近奇异、角动量接近满量程、框架速率饱和；
5. **A 组失败归因**：不是求解失败（fallback ≈ 0、约束违反 ≈ 0），而是气动力矩能力不足；
6. **实时性**：22 次运行中 20 次的单步 P95 ≤ 172 ms（在 0.2 s 内），P1 的 S01/S06 两次运行达到 284/412 ms，需要降低 QP 次数或触发回退才能进预算；
7. 唯一明显回退是 S06-P1（B 组 0.652°），需要时可在该情形切回非线性求解器。
