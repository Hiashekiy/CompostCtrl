### 1.2 五项确认

1. **`tau_nom` 就是参考姿态轨迹对应的需求力矩。** 用与代码完全相同的口径独立复算（`omega_ref` 中心差分 `eps=0.05 s`、`H_nom` 取**规划时刻**（上一样本）的 γ、扰动取配置的 `trajectory3.disturbance`），与 CSV 的 `tau_nom_y` 最大偏差 = **4.56e-08 N·m**。
2. **`lo_y`/`hi_y` 是俯仰方向舵面可实现的总气动力矩上下界。** `y` 为机体俯仰轴；盒由 `nat_ref ± 0.774·hull(Q,δ_max)` 给出，0.774 是 `results/torque_gap/model_checks.json` 标定的保守比例（≥99% 盒内样本可被有界舵偏实现）。t=90 s 时 `[-40.03, 34.08] N·m`，与面板 3 灰带一致。
3. **`tau_act_y` 是实际气动力矩、`cmg_y` 是实际 CMG 力矩。** 本运行是 **P0 虚拟力矩植物**：舵面被抽象为理想力矩执行器，因此 `tau_act_y ≡ tauc_cmd_y`（最大偏差 0.0e+00 N·m）；这**不是**真实舵偏角实现，真实舵面见 P1 运行。`cmg_y` 用真实 γ,ν 通过 `−A(γ)ν` 复算，与 CSV 最大偏差 = 9.07e-08 N·m。
4. **参数全部取自本次运行的 `config_resolved.yaml`**：`h0 = 50.0 N·m·s`、`gdot_max = 1.50 rad/s`、`gddot_max = 10.0 rad/s²`、`β = 54.7356°`；未使用类默认值。
5. **两个执行机构之和就是控制力矩，没有隐藏补偿项。** 机体系力矩方程为 `J ω̇ = τ_a − A(γ)ν + τ_d − ω×(Jω+H)`，故 `τ_a + τ_cmg` 等于控制力矩；陀螺项 `−ω×(Jω+H)` 与扰动 `τ_d` 不属于执行机构输出，面板 2 未把它们并入。量级（由 CSV 的 `wx/wy/wz`、`H` 与配置扰动模型算出）：实际陀螺耦合项 `−ω×(Jω+H)` 的**俯仰分量** 90–110 s ≤ 0.05 N·m、110–130 s ≤ 0.06 N·m；三轴最大 0.32 / 1.22 N·m；扰动 ‖τ_d‖∞ ≤ 0.50 / 0.50 N·m。

### 1.3 CSV 的时间对齐约定（重要）

日志的行序是“先执行、后记录”：第 k 行的**状态列**（`q, w, g, H, sigma_min`、以及由它们算出的`att_err_deg`、`cmg_*`、`E_gap`）是**该控制周期结束时**的状态，即物理时刻 `t_k + dt_ctrl`；而**计划列**（`tau_nom_*`、`Rp_*`、`Rm_*`、`d_*`、`lo_*`、`hi_*`、`qref*`、`wref*`）是在 `t_k` 时刻算出的；指令列（`tauc_cmd_*`、`tau_act_*`、`nu*`）是在 `[t_k, t_k+dt_ctrl]` 内施加的。

因此本图的**状态类曲线按 `t + dt_ctrl` 绘制**（其真实物理时刻），计划/指令类曲线按 `t` 绘制；`att_err_deg` 本身混用了两种时刻（`t_k+dt` 的状态对 `t_k` 的参考），故未直接使用，面板 1 的俯仰角分别由 `q`（+dt）与 `qref`（t）算出。事件竖线用绝对时刻标注。

## 2. 派生量的公式与参数来源

| 派生量 | 公式 | 参数来源 |
|---|---|---|
| 俯仰角 | `θ = asin(2(wy − zx))`（`model6.quat_to_euler` 的 ZYX 定义） | 项目四元数约定（未改） |
| 瞬时俯仰能力 | `τ⁺_max,y = max_{ν∈U} e_yᵀ(−A(γ)ν)`，`τ⁻_max,y = min_{ν∈U}(…)`，`U = {|ν_i| ≤ 1.50 rad/s}` | `A(γ)`、`gdot_max` |
| 解析等价 | `τ⁺_max,y = −τ⁻_max,y = gdot_max·Σ_i|A_yi(γ)|`（与 16 顶点枚举最大差 5.7e-14 N·m） | 同上 |
| 能力利用率 | `|τ_cmg,y| / min(τ⁺_max,y, |τ⁻_max,y|)`，**逐样本**计算 | CSV + 上述能力 |
| 缺口覆盖残差 | `‖τ_cmg − d‖`（CSV `gap_residual`） | 已记录 |

关于 `U`：框架**加速度**约束是 `|ν_k − ν_{k−1}| ≤ gddot_max·dt` 的逐步约束，不改变某一时刻的瞬时可达集，故能力计算只用 `|ν_i| ≤ gdot_max`；这与 `torque_gap_ocp.py` 中“速率盒 + 增量约束”的写法一致。

## 4. 力矩分工（俯仰轴；均值 / 峰值 / RMS，N·m）

| 区段 | 需求 `τ_nom` | 舵面 `τ_a` | CMG `τ_cmg` | 合成 `τ_a+τ_cmg` | 需求−合成 |
|---|---|---|---|---|---|
| 90–110 s（迁移/准备） | -1.39 / 1.64 / 1.40 | 7.32 / 29.48 / 10.33 | -7.66 / 20.84 / 10.22 | -0.35 / 33.72 / 7.08 | -1.04 / 35.35 / 7.10 |
| 110–130 s（主机动） | -0.63 / 64.61 / 45.63 | -3.12 / 18.13 / 10.40 | 1.28 / 77.25 / 39.11 | -1.84 / 92.00 / 47.31 | 1.21 / 41.51 / 13.74 |

- 舵面与 CMG 的**反号比例**（舵面在抵消 CMG 反作用力矩）：迁移段 75%、机动段 9%。
- 迁移段：舵面均值 7.32 N·m、CMG 均值 -7.66 N·m，两者近似相消，合成仅 -0.35 N·m，姿态保持在被控范围内（见 5.1）——这就是“气动富余抵消 CMG 迁移反作用力矩”。
- 机动段：舵面均值 -3.12 N·m、CMG 峰值 77.2 N·m；需求−合成的均值为 1.21 N·m。

**“需求−合成”这一列是什么？** 不是建模误差，而是闭环的**反馈修正**。由
`J ω̇ = τ_a + τ_cmg + τ_d − ω×(Jω+H)` 与 `τ_nom = J ω̇_ref + ω_ref×(Jω_ref+H_nom) − τ_d` 可得

```
(τ_a + τ_cmg) − τ_nom = J(ω̇ − ω̇_ref) − [ω×(Jω+H) − ω_ref×(Jω_ref+H_nom)]
```

扰动 τ_d **精确抵消**，因此残差只由“反馈角加速度修正”与“陀螺项变化”两部分构成；它的存在正是任务书 §2.3 所说“前馈需求在存在当前误差/扰动时会低估需求”。

该式**不能**用本 CSV 做逐点数值核对：`J_y = 8500 kg·m²`，`ω` 仅 0.2 s 采样且力矩为零阶保持，`ω̇` 的差分误差会被 `J_y` 放大到几十 N·m；此外状态列比计划列晚一个控制步（见 §1.3）。因此改用下面更强的“状态复现”检验。

**状态复现检验（无隐藏力矩项）：** 取第 k−1 行的状态、第 k 行的指令 `[τ_a, ν]` 与配置扰动，把 11 状态 P0 模型积分一个控制周期（`dt = 0.20 s`，8 子步，与仿真植物完全相同的步进方式），再与第 k 行状态比较；共 299 个区间，最大偏差为：

| 状态分量 | 最大偏差 |
|---|---|
| 机体角速度 `[p,q,r]` | 3.84e-09 rad/s |
| 框架角 `γ` | 1.00e-09 rad |
| 四元数 `q` | 2.14e-10 |

偏差在数值积分精度量级，说明**日志中的舵面力矩与 CMG 力矩、加上模型自身的陀螺项和扰动，即可完整复现被控对象的状态演化**，不存在被遗漏或重复计入的补偿力矩。

## 5. 关键问题

### 5.1 提前构型迁移发生的时间
t ≈ **90.8 s**（机动前 19.2 s）；此后 γ 持续变化，t ≈ 95.8 s 首次越过 90°。迁移段（90.8–110 s）俯仰角误差最大 0.199°、RMS 0.095°（90–110 s 全段最大 0.199°），说明**准备动作没有破坏姿态稳定**。

### 5.2 迁移期间舵面与 CMG 的分工
见 §4：舵面均值 7.32 N·m 与 CMG 均值 -7.66 N·m 反号（75% 的样本反号），合成力矩仅 -0.35 N·m。即准备阶段**舵面维持姿态、CMG 主动改变构型**。

### 5.3 主机动期间舵面是否出现能力不足
**是。** 机动窗口内 `d_y ≠ 0` 的样本占 92%，`|d_y|` 峰值 **57.2 N·m**（t = 114.4 s，方向 + y）；`d_y` 超过同时刻瞬时 CMG 能力的样本占 1%；`tau_bound_used` 在机动窗口均值 0.61（3 个轴中处于气动盒边界的平均比例）。因此需求超出预测气动盒时，缺口只能由 CMG 承担，舵面在部分时段贴边工作。

### 5.4 迁移到底改变了什么：为什么“能力上下限”反而变小

**先说结论：迁移的目标不是瞬时力矩包络，而是俯仰轴角动量 `H_y`。** 本运行里 `H_y` 的变化：

| t [s] | 90 | 95 | 100 | 105 | 108 | 110 | 112 | 120 |
|---|---|---|---|---|---|---|---|---|
| `H_y` [N·m·s] | 0.1 | 23.5 | 98.1 | 148.4 | 156.0 | 155.6 | 140.3 | -155.8 |

即 `H_y` 从 0.09 被**预置到 155.6 N·m·s**（t=110 s），而该轴角动量的可达上界是 `h0·Σ_i√(s0_iy²+(g_i×s0_i)_y²) = 157.74 N·m·s`，已经用到 **98.7%**。

**力矩包络必然同时塌陷，这是数学恒等式而非缺陷：**

```
H_y(γ) = h0 Σ_i s_i,y(γ_i),     ∂H_y/∂γ_i = h0 (g_i × s_i(γ))_y = A_1i(γ)
τ⁺_max,y = gdot_max Σ_i |A_1i(γ)|   ←  正是 H_y 对 γ 的梯度（L1 形式）
```

把 `H_y` 推到可达集极值点 ⇒ 该点的梯度 `A_1i` 全部为零 ⇒ `τ⁺_max,y → 0`。数值验证：在 `H_y` 取最大值的构型 γ = [-0.0, -90.0, -180.0, 90.0]° 处，`Σ_i|A_1i| = 5.75e-15`、`τ⁺_max,y = 8.62e-15 N·m`（home 构型是 86.6 N·m）；而本运行 t=107–111 s 的 `σ_min` 最小已降到 **0.25**（home 40.7），说明构型确实停在“角动量饱和”的近奇异点附近。

### 5.5 那么迁移算不算“成功”？用对判据

力矩 `τ_cmg,y > 0` 会让 `H_y` 减小（`dH_y/dt = −τ_cmg,y`），所以未来需要 **+y 力矩**时，可用裕度是 `H_y − H_y,min`；需要 **−y 力矩**时是 `H_y,max − H_y`。用真实数据：

| 时刻 | `H_y` [N·m·s] | 可供 **+y** 力矩消耗的裕度 [N·m·s] | 可供 **−y** 力矩消耗的裕度 [N·m·s] |
|---|---|---|---|
| 90 s（未迁移） | 0.1 | 157.8 | 157.6 |
| 110 s（迁移完成） | 155.6 | **313.4** | 2.1 |

机动第一阶段（110–115 s）缺口为 **+y**（峰值 57.2 N·m），消耗的正是“+y”裕度：该裕度在迁移中从 157.8 增加到 **313.4 N·m·s（×1.99）**；机动第二阶段（120–130 s）缺口转为 **−y**，所需的“−y”裕度由 `H_y` 在第一阶段下降后自动腾出。

**因此：迁移是成功的——它把俯仰轴角动量预置到了将来要消耗的那一侧，可用角动量裕度翻倍；但瞬时力矩包络必随之下降，用“`τ⁺` 有没有变大”来评判迁移是选错了判据。**（本报告 §5.4 初版以及 `unlimited_gimbal_experiment.md` §5.4 中“迁移没有提高能力”的说法，按此判据应当修正为：*迁移不改变（且必然压低）瞬时包络，但显著增加弯矩方向的角动量裕度*。）

仍要强调：`H_y` 是**角动量**，不是力矩储备。它决定“还能在该方向持续输出多久”（时间 ≈ 裕度 / 需求力矩），不能直接读成“还能出多大扭矩”。

另外，实际 `H_y` 的摆幅（+156 → −156，约 312 N·m·s）明显大于 110–130 s 的缺口积分（`∫d_y dt ≈ +77 N·m·s`）：差额来自 CMG 还要承担瞬态、以及指令抖振造成的往复，因此**不能把 `ΔH_y` 与 `∫d dt` 一一对应**，也不能据此反推“迁移量是否刚好够用”。

### 5.6 瞬时能力曲线本身（仅供参考）

由真实 `A(γ)` 逐样本算得（这是**瞬时**能力，不是迁移的目标，也不是可持续能力）：

| t [s] | `τ⁺_max,y` [N·m] | `τ⁻_max,y` [N·m] |
|---|---|---|
| 90 | 87.6 | -87.6 |
| 95 | 166.9 | -166.9 |
| 100 | 129.0 | -129.0 |
| 105 | 69.0 | -69.0 |
| 110 | 31.9 | -31.9 |
| 112 | 105.1 | -105.1 |
| 120 | 32.8 | -32.8 |
| 125 | 175.4 | -175.4 |

- 迁移段 `τ⁺_max,y` 中位数 108.6 N·m，机动段中位数 126.6 N·m（机动段最大 231.6 N·m）。
- 缺口峰值时刻（t = 114.4 s）需求方向为 + y，该方向的瞬时可用能力 231.6 N·m，而缺口为 57.2 N·m（能力/需求 = 4.05）。
- 该能力曲线逐样本**剧烈起伏**（≈30–230 N·m），因为 γ 每个控制周期都被重解、存在指令抖振（`τ_a` 每步跳变约 2 N·m，ν 符号翻转约占 57% 的控制步）。因此逐点比较没有意义，**只能看区间统计量**（上表中位数）。
- 瞬时能力在多数时刻仍然够用：机动窗口内只有 1% 的样本 `|d_y| > min(τ⁺,|τ⁻|)`。**本工况的真正瓶颈是可持续输出（角动量/框架速率预算），不是瞬时包络**。

### 5.7 实际输出与瞬时能力的关系
机动窗口内逐样本能力利用率 `|τ_cmg,y| / min(τ⁺,|τ⁻|)`：中位数 24%、最大 59%；“全部样本满足 `|τ_cmg,y| ≤ min(τ⁺,|τ⁻|)`”这一自洽性检查：**通过**。
即实际输出始终落在瞬时能力带内，但**中位数只用到 24%**——这正说明“瞬时能力 ≠ 可持续输出”：真正的限制是角动量与框架角速度预算，而不是某一时刻的最大力矩（同一结论见 `docs/torque_gap/unlimited_gimbal_experiment.md` §5.2）。

### 5.8 当前数据**不能**证明的结论

1. **未来持续力矩能力 / “力矩储备”**：CSV 只保存当前节点的 `τ_nom`、`d`、`lo/hi`，**没有**保存预测时域内各节点的 `τ_nom(k)`、`d(k)`，因此无法从归档数据画出“未来需求方向”曲线，也无法给出按未来方向折算的持续能力。面板 5 因此只画**瞬时**能力，未给出任何“剩余储备”指标。
2. **角动量储备**：`|H|` 的几何上界为 `4h0 = 200 N·m·s`（实际可达 ≈162.9），但本图没有把 `|H|` 当作力矩储备；要回答“还能持续多久”需要对未来需求做时间积分，归档中不完整。
3. **真实舵偏角实现**：本运行是 P0（理想力矩执行器），`tau_act_y ≡ tauc_cmd_y`，不能据此断言真实舵面可达到同样力矩；对应结论须用 P1 运行（`results/torque_gap_unlimited/C1_B0_P1/`，本次未画）。
4. **因果性**：本图是单次闭环运行的时序，不构成“提前迁移导致跟踪改善”的因果证据；该判断依赖 B0/B1/B2 与 C4 对照（`docs/torque_gap/unlimited_gimbal_experiment.md`、`results/torque_gap_unlimited/summary.md`）。
