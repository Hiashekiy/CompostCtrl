构造要点（细节见审计文档 §12）：

- 参考飞行条件（原始 S00/S03 轨迹 t = 90 s）：h = 89.75 km，ρ = 2.739e−6 kg/m³，
  V = 3640 m/s，**Q0 = 18.147 Pa**，M = 12.64，Kn = 0.009。
- A1–A3 用**平飞定常条件**构造（`trajectory.amp = 0`、`dVdt = 0`）：
  γ ≡ 0、ρ、V、M、Kn、q̄ 在整窗口恒定，`α_ref ≡ alpha_trim`，唯一变化的是设定的 α 或 q̄。
- 每个受控工况都在 110–130 s 叠加**同一条 +8° 俯仰凸起参考**（`shape: bump`，两端归零），
  以便在"保持能力"之外还测到"加载能力"（舵面力矩、CMG 负载、跟踪误差）；
  这个机动对所有工况完全相同，因此工况之间的差异仍然只有 α / q̄。
- 气动扰动按原弹道的物理规律缩放：`vehicle3.Md_amp` 以 30 km / 4000 m/s 的参考点定义
  （q̄ = 133832 Pa），每个受控工况按 `q̄_case / q̄_ref` 折算，使同一 q̄ 下受控工况与
  A4 复现看到的外扰一致（≈ `Md0 = [0.2, 0.5, 0.3] N·m`）。
  若不折算，`dist_scale_qinf` 会以工况自身的 q̄ 作参考，把气动外扰放大到 20 N·m 量级，
  受控实验将无法与原始弹道对照（详见审计 §12.3）。
- 统计区间：全程 90–150 s；主区间 = 指令机动窗口 110–130 s（A1–A3 的 +8° 凸起、
  A4 的 +30°/+45° 机动）；末段 = 130–150 s。
- 求解器：HPIPM RTI，`qp_iters = 12`，`state_tr_gamma = 0.5`，`state_tr_omega = 1.0`，
  接受策略 `accept_feasible: false`（不收敛/违约步不使用，改用记录在案的 fallback）。
- 72 次运行中只有 3 次出现回退（最大 0.67%，均为 S03/B），**所有退化都不是求解器回退造成的**。
- 求解耗时：单步 P95 中位数 0.135 s、最大 0.553 s；6% 的运行 P95 超过 0.2 s 控制周期
  （本轮 6–8 进程并行，wall clock 含 CPU 争用）。按方案 §12，耗时只作参考。

判读：

1. `|α| ≤ 20°`：两臂都能保持，但**差距随迎角拉大**。A 组 RMSE 从 α=0 的 0.044° 涨到
   α=20° 的 0.745°（主区间 1.16°，最大 1.59°，`t>1°` = 109.4 s，贴边 18.4%）；
   B 组始终 ≤ 0.005°，**但代价是角动量**：`|H|` 峰值从 α=0 的 66.3 涨到 112.5 N·m·s
   （满量程 200 的 56%），σ_min 从 40.8 掉到 2.8（奇异下限 12.25），
   持续同向俯仰力矩时间 4.0 s → 18.2 s。
2. 非单调：α = 0 时误差最小（配平需求为零），±10° 时误差上升到 0.17–0.25°。
   ±10° 不对称（A：0.250 vs 0.167）：能力盒以 τ_nat 为中心，α>0 时自然力矩为抬头，
   而 +8° 凸起也要抬头力矩，两者的可用余量方向相同 → 正迎角 + 抬头机动是最不利组合。
3. `α = 30°/40°`：两臂同时失去保持能力（误差 48–83°）。此时舵面在**参考状态**下已到
   0.933 / 1.244 的需求比，而控制器的保守盒（0.7738×）在 α ≈ 25° 就先到 1.0，
   于是 MPC 干脆无法再要求足够的舵面力矩，飞行器滑向另一个配平点。
   B 组用 CMG 撑了一段（`|H|` 顶到 163/200 = 82%，σ_min 0.05–0.1，框架速率饱和 0.7–5.7%），
   但最终同样失效，S08-1 面板 (f) 显示 CMG 负载随 α 单调上升。
4. **迎角效应不是气动系数非线性**：整个扫描中实测 `C_m` 全部落在 `C_m = −0.35·α` 直线上
   （图 S08-1 面板 (a)），`Cm_δe` 与 α 无关，`τ_half,y` 恒为 47.89 N·m。
   变化的是**需求**，不是效能。

## 3. S08-A2：固定迎角 2°，改变动压（P0 / P1）

P0：

| q̄ | 舵面半宽 τ_half,y | A 全程 RMSE | A 最大误差 | A 贴边 | B 全程 RMSE | B \|H\|峰值 |
|---|---|---|---|---|---|---|
| 9.07 Pa (0.5Q0) | 23.94 N·m | 0.559 | 1.474 | 12.3% | 0.005 | 106.2 |
| 18.15 Pa (Q0) | 47.89 N·m | 0.048 | 0.160 | 3.1% | 0.003 | 74.8 |
| 36.29 Pa (2Q0) | 95.78 N·m | **0.000** | 0.002 | 0% | 0.000 | 0.2 |
| 72.59 Pa (4Q0) | 191.56 N·m | **0.000** | 0.002 | 0% | 0.000 | 0.1 |

P1：A 组 1.714 / 2.227 / 1.416 / 0.004°，B 组 0.018 / 0.018 / 0.067 / 0.004°。

判读：

1. **动压升高不引起退化，反而改善跟踪**（0.559° → 0.000°，单调）。
   固定迎角时气动配平力矩与舵面能力同比例随 q̄ 增长，需求/能力比不变（参考状态恒为 0.062）；
   变的是舵面**绝对**可用力矩（23.9 → 191.6 N·m）和控制力矩的**速率**能力（∝ q̄）。
2. 唯一出现退化的仍是**低动压端**（0.5Q0 = 9.07 Pa）：A 组 `t>1°` = 111.4 s、贴边 12.3%；
   B 组靠 CMG（`|H|` 峰值 106.2，σ_min 5.1）保持 0.005°。
3. 因此方案假设 H2（"动压增加 → 气动负载增大 → 控制余量下降"）在本模型中**不成立**：
   负载与能力同倍增长；真正吃掉余量的是**迎角**（配平需求 ∝ α·q̄）与
   **与 q̄ 无关的残余扰动**（Md0）。这解释了 A4 中"低动压段失效"而不是"下降段失效"。

5. P1 下同两工况：S00 A 6.256° / B 0.381°；S03 A 18.074° / B 7.636°。
   方向与 P0 一致（S00 中 CMG 大幅改善；S03 中改用真实舵面后 B 仍好于 A），
   但幅度整体放大 1.2–2.2 倍，说明**真实执行链放大退化**。

## 6. 种子稳健性（A4，扰动相位随机化，A/B 同种子）

|---|---|---|---|---|---|---|

- 模型完全确定：`seed_randomize: false` 时同配置逐位可复现（§1），因此 A1–A3 用单一种子；
  随机化只改变正弦扰动的相位。
- S03/A 对相位几乎不敏感（极差 0.006°）→ 该退化由确定性的能力不足主导；

  所以 S03/B 只能表述为"平均更差、且不确定性更大"。

## 7. 逐条回答方案 §16 的十个问题

1. **S00/S03 实际迎角在失效前如何变化？** 参考迎角在 110 s 前恒为 2°，随后按 +30°/+45°
   五次曲线在 110–130 s 内升到 32°/47° 并保持。仅舵面臂在失效前就已偏离参考
   （S00：t = 110 s 时 α = 6.0° 而参考 2.0°；S03：t = 105 s 时 α = 3.8°），
   失效后跌向另一个配平点；B 组在 147 s 前把 α 跟踪在参考 ±0.3° 内。
2. **末端动压增长了多少倍？** 窗口内 q̄ 从 17.8 Pa 降到 3.31 Pa（120 s）再回到 17.8 Pa
   （150 s），顶点到末端 **5.37 倍**；相对窗口起点没有净增长。
   动压**最低**的时刻（120 s）正是舵面权限最差、CMG 角动量消耗最猛的时段。
3. **当前气动模型是否覆盖对应迎角、马赫数与稀薄程度？** 不覆盖。没有任何声明的适用范围；
   `Cm` 对 α 线性到 40°；气动系数与马赫数无关；Kn = 0.002–0.018（稀薄过渡区）无修正。
4. **CL、CD、Cm 是否出现非线性变化？** CL、CD 在本模型中不存在（无力方程，日志中为空列）。
   `Cm` 严格线性（S08-1 面板 (a)：实测点全部落在 `Cm = −0.35α` 直线上），
   扫描到 40° 也没有拐点 → **本模型不可能给出失速证据**。
5. **舵面控制效能是否下降，还是控制需求单纯增大？** 是**需求增大**、效能不变：
   A1 中 `τ_half,y` 恒为 47.89 N·m（与 α 无关），配平需求每 10° 增加 14.9 N·m；
   A2 中效能随 q̄ 线性增长（23.9 → 191.6 N·m），需求几乎不变，util 随 q̄ 下降。
6. **舵面何时开始饱和，当时可用俯仰力矩是多少？** S00/A 从 97.2 s 起持续贴边
   （q̄ ≈ 8 Pa，可用俯仰半宽 ≈ 18 N·m，为 Q0 时的 38%）；S03/A 从 95.8 s 起。
   A1 在 q̄ = 18.15 Pa 时：α = 30° 需求/能力 0.933、α = 40° 为 1.244（物理不可配平）；
   控制器保守盒（0.7738×）使该比例在 α ≈ 25° 就先到 1.0。
7. **CMG 何时出现速率饱和、角动量接近边界或近奇异构型？** S00/B：`|H| ≥ 50%` 在 102.2 s、
   σ_min 触及 12.25 下限在 107.2 s（最低 0.6–1.04）、持续框架速率饱和 147.4 s，
   `|H|` 峰值 160.8（80%）。S03/B：98.4 s / 102.8 s / 111.8 s，`|H|` 峰值 159.8，σ_min 0.1。
   A1 中 `|H|` 峰值随 α 单调上升：66.3（α=0）→ 112.5（20°）→ 163.3（40°）。
8. **A/B 两组分别在何时开始持续失效？** S00：A 102.6 s，B 148.2 s（延后约 46 s）；
   S03：A 99.2 s，B 110.8 s，但 B 在 137.8 s 越过 5°、142.0 s 越过 10°，末段比 A 更差。
9. **迎角、动压和二者耦合哪个贡献最大？** 本模型里**迎角是决定性因素**：它决定配平需求是否
   超过舵面能力（A1：20° 起明显退化、30° 崩；A2：动压 8 倍范围内固定 α 无退化）。
   动压只决定"能力"以及"越界后的力矩幅度与演化速度"。A3 的正交互项（RMSE +55.5°/+52.3°）
   说明组合后果远大于线性叠加，但机制是"迎角触界 + 动压放大后果"，不是气动系数非线性。
10. **当前模型是否足以支持"失速"结论？** 不足以。缺少 `CL(α,M,δe)`、`CD(α,M,δe)`、
    非线性 `Cm(α,M,δe)`、马赫/雷诺/稀薄修正，以及任何可追溯的风洞或 CFD 数据。

## 8. 结论分层

### 8.1 代码与实验直接证明的事实

1. 模型只有姿态自由度，无升力/阻力；气动系数与 α 线性、与 M/Re/Kn 无关
   （审计 §1–§4；实测 Cm 点全部落在理论直线上）。
2. 舵面控制效能只由 q̄ 决定（`τ_half ∝ q̄`），与 α 无关；配平需求随 `α·q̄` 线性增长。
3. 原始 S00/S03 结果被逐位复现（差 0.0e+00）；A/B 差异只有 CMG 开关。
4. A1：随 α 增大，仅舵面臂的 RMSE 从 0.044°（0°）单调升到 0.745°（20°，贴边 18.4%），
   α ≥ 30° 时两臂同时失去保持能力；B 组全程 ≤ 0.005°，但 `|H|` 用到 56–82%、
   σ_min 最低 0.05–0.1。
5. A2：固定 α = 2°、q̄ 提高 8 倍（9.07 → 72.59 Pa）跟踪反而从 0.559° 改善到 0.000°；
   退化只在低动压端出现。
6. A3：二维交互项显著为正（A +55.52°、B +52.27°）；B 组在低动压高迎角组合里能把
   25.14° 压到 5.43°，在高动压高迎角组合里仍达 57.70°。
7. A4：S00 中 A 组 97.2 s 起持续贴边、102.8 s 起误差持续 > 1°；B 组延后到 148.4 s，
   期间 `|H|` 用到 80%、σ_min 掉到下限以下（最低 0.6）。S03 中 B 组全程（9.49°）
   反而不如 A 组（8.26°），末段差 16.17° vs 8.32°。
8. P1 真实舵面植物下趋势一致但幅度放大：S00 A/B = 6.26°/0.38°，S03 A/B = 18.07°/7.64°；
   即使 α ≈ 0，仅舵面臂也有 2.3–3.0° 的固有跟踪误差（舵机与分配限制）。
9. 全部退化与求解器回退无关（回退 ≤ 0.7%，只有 3 次运行出现回退）。

### 8.2 受控实验支持的物理解释

1. 退化主线是**"配平/机动需求（∝ α·q̄，叠加与 q̄ 无关的残余扰动 Md0）超过舵面可用力矩
   （∝ q̄·δmax）"**，不是气动系数变化。这同时解释了 A1 的 α 阈值、A2 的"动压越高越好"、
   A4 低动压段失效。
2. CMG 的作用是**推迟失效**：在 α = 20° 与 S00 下降段它补上缺口，代价是持续的角动量消耗
   与框架迁移（`|H|` 56–80%、σ_min 触底）。H4 在本轮被量化。
3. S03（+45°）上 CMG 反而使结果更差，可解释为：暂态阶段把储备一次用尽
   （近奇异 + 持续速率饱和），到高 q̄ 段没有储备可用，且失去储备后恢复比纯气动更慢。
4. 建模保守性带来额外能力损失：气动能力盒标定系数 0.7738 把"可配平迎角"
   从物理值 ≈32° 压到 ≈25°（A/B 相同）。

### 8.3 仍需真实气动/高保真模型验证的推测

1. 真实飞行器在 30–47° 迎角下是否出现 `Cm` 非线性、失速、舵效下降 —— 本模型无法回答；
   需要 `CL/CD/Cm(α, M, δe)` 的风洞/CFD 数据（A5 未执行，见 §9）。
2. 81–94 km、M ≈ 12.6、Kn 0.002–0.018 的稀薄效应对气动系数与舵面效能的影响未建模；
   若稀薄效应使 `Cm_δe` 衰减，则"舵面效能与 α 无关"的结论需要改写。
3. 无平动方程 ⇒ 迎角是纯运动学量。真实飞行中 α 变化会同时改变速度、高度和 q̄，
   本轮把它们人为解耦（定常条件 + 统一凸起），A1–A3 的定量边界不能直接外推到真实弹道。
4. 质量/惯量不含 4×30 kg 的 CMG 硬件（沿用历史结论：无法从现有数据剥离），
   属"匹配惯量的算法对照"。

## 9. 本轮边界与未执行项

- **A5（非线性气动对照）未执行**：审计确认当前模型确实是线性模型（满足执行前提），
  但仓库内没有任何可追溯的气动数据；方案 §9 禁止人为构造失速曲线。
