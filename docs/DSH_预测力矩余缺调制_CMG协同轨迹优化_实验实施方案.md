## 0. 任务范围与不可改变的设计

采用**联合优化**，不是旧版 `[舵偏角, CMG 指令力矩]`，也不是“上层构型规划 + 下层姿态 MPC”。

- 优化状态：`x=[q(4), omega(3), gamma(4)]`，11 维（四元数单位范数）；预测时必要时增设 `nu_actual(4)` 以处理框架速率环，但必须将 11 状态方案作为第一版名义模型，并说明选择。
- 优化输入：`u=[tau_a(3), nu(4)]`，7 维。`tau_a` 是**合成三轴气动力矩 [N·m]**，不是舵角，也不是舵角指令；`nu` 是 CMG 框架速率 [rad/s]。
- 优化输出：气动力矩预测/执行轨迹、框架角速度轨迹和积分得到的四维构型轨迹；姿态参考是主目标。
- 对舵面只提供随时间变化的三轴可用力矩上下限（首版盒约束）；不将舵角/舵机动态纳入**预测优化器**。
- 预测调制输入：各时刻三轴的 `R_plus = tau_a_max - tau_nom`、`R_minus = tau_nom - tau_a_min`、`d = tau_nom - clip(tau_nom, tau_a_min, tau_a_max)`。**`d` 正负表示实际缺失力矩的方向；R 的正负表示该方向有余量还是越界。** 单位均为 N·m，不额外引入惯量/效率权重。
- 未来缺口用于 **构型能力软代价**，当前气动富余通过时变气动力矩上下限和耦合姿态动力学决定迁移是否可被补偿。不得将 `R_plus/R_minus` 再写一套重复硬约束。
- 不把 `sigma_min(A)` 最大化或其最低阈值写成主方案强制约束。真实关注的是任务方向的力矩匹配；可单独记录奇异值作为诊断。
- 不为获得“好结果”人为放大气动弱化、缩小舵面能力或改变真实动力学。所有参数/简化必须明确记录。

## 2. 算法核心：预测模型与调制定义

### 2.1 简化飞行器–CMG 联合模型

采用 `q=[w,x,y,z]`、`omega=[p,q,r]`、`gamma=[γ1..γ4]`，动力学：

\[
\dot q=\tfrac12 q\otimes[0,\omega],\quad
J\dot\omega=\tau_a-A(\gamma)\nu+\tau_d-\omega\times(J\omega+H(\gamma)),\quad
\dot\gamma=\nu.
\]

其中 `H(gamma)` 与 `A(gamma)` 必须调用 `CMGCluster`，`tau_d` 的使用和真值模型保持一致。四元数积分每步归一化，姿态误差使用短弧四元数误差/测地角，`q` 与 `-q` 等价。明确当前 J 是与原 `model6c` 相同的等效惯量定义，避免重复计入转子角动量。

**关键一致性测试**：同一个 `q,ω,γ,ν,τd`，给真实植物设置气动力矩与虚拟模型的 `τa` 相同（跳过舵面映射，仅在单元测试中注入力矩），两者的 `ωdot` 必须在数值容差内相等；验证 `dH/dt=A(γ)ν` 与 `τcmg=-Aν`。不能把不同接口默认视为等价。

### 2.2 随时间变化的三轴气动力矩盒

`tau_min[k,3]`、`tau_max[k,3]` 来自预测 `h(t),V(t),rho(t)` 与已有气动系数、舵偏限幅的**离线评估**：首先计算在参考/名义状态下可实现的气动力矩集合，再给出保守的逐轴同时可实现范围。若简单独立取三轴极值会造成不可同时实现，至少提供一个**投影/最小二乘反算舵偏**的可行性检查，并以保守缩放系数配置，记录盒内随机样本的舵面可实现率；如达不到要求，收缩边界，不得假定三轴完全独立。

**区分气动力矩的总值与控制增量**：原 `aero_moment6c` 包含固有气动项、气动阻尼项、舵面项；`tau_a` 定义为合成总气动力矩，导出边界及实际反算时必须保持同一口径，不能把自然力矩算两次。角度单位全部用 rad，力矩 N·m。

首版支持 **两套实验植物**：

- **P0 虚拟力矩植物（算法原理验证）**：直接以 `[tau_a,nu]` 驱动上述 11 状态动力学，盒约束保证力矩输入合法；与优化器模型一致，最容易定位算法是否有效。
- **P1 舵面真值植物（模型泛化验证）**：保留原有 `model6c` 的 18 状态+真实舵面/速率环，增加独立气动力矩→舵偏角分配器；输出实际力矩与期望 `tau_a` 的误差。**P1 与 P0 结果不能混作同一结论**；如果 P1 明显失败，先定位气动力矩盒不真实或分配误差，不要修改主算法来掩盖。

P1 的分配器在每个采样时刻用已有气动模型反求 `delta_cmd`（受舵偏角、速率、动态限制）；给定动压与局部气动 Jacobian，可求有界最小二乘。若无法达到目标，真实执行可实现解并记录残差。P1 暂不要求作为第一阶段通过门槛。

### 2.3 余缺预测（不施加额外舵面效率/惯量权重）

从平滑参考 `qref,ωref,ωdot_ref` 按与模型一致的机体系定义估算名义**总外部控制力矩** `tau_nom[k,3]`：

\[
\bar\tau_d =J\dot\omega_{ref}+\omega_{ref}\times(J\omega_{ref}+H_{nom})-\tau_{d,nom}.
\]

`H_nom` 首版统一选为 **当前 H 在预测窗口内冻结** 或零，做成显式配置并在所有比较组保持一致；参考角速度必须是与 `qref` 对应的**机体系速率**，不能直接把 Euler 角导数当作机体系速率。上述只是名义**总控制力矩需求**，不预分配给舵面/CMG。

\[
R^+_k=\tau^{max}_{a,k}-\bar\tau_{d,k},\quad R^-_k=\bar\tau_{d,k}-\tau^{min}_{a,k},\quad
d_k=\bar\tau_{d,k}-clip(\bar\tau_{d,k},\tau^{min}_{a,k},\tau^{max}_{a,k}).
\]

`R+/R-` 是**带符号的方向余量**，`d` 是**带实际力矩方向的缺口**。`R+/-`不需被压成标量，也不需要转为 sigmoid。要求日志保存每个窗口的 `tau_nom, R+, R-, d, tau_min, tau_max`，以及 `d` 首次非零的提前预告时间；以独立算例检查负向缺口符号。

**关键限制**：单纯前馈参考加速度在“保持姿态但存在当前误差/扰动”时可能低估需求。第一版坚持文件定义的名义需求提取，不偷换成优化后实际 `tau_a`；另单独记录这一近似对闭环的影响。

## 3. 联合轨迹优化问题：目标、约束、求解

### 3.1 目标函数

主项 `J_att`：预测各节点四元数姿态误差与机体系速率误差；终端姿态权重。默认权重使姿态跟踪优先。

调制项 `J_cfg`：对 `d_k` 非零节点，测量候选 `gamma_k` 对该三轴缺口的最佳**瞬时匹配残差**：

\[
E_k(\gamma_k)=\min_{|v_i|\le v_{i,max}}\| -A(\gamma_k)v-d_k\|_2^2,
\qquad J_{cfg}=\sum_{k=1}^{N}w_kE_k(\gamma_k).
\]

仅在 `d!=0` 时启用（`d=0` 本身对应 `E=0`）。`v` 是**能力评估的辅助变量，不是实际 `nu`**。为避免在 NLP 中嵌入不可微的内层最小值，建议直接引入每个节点的辅助变量 `v_eval[k,4]`，对其加速率盒界，最小化 `||-A(gamma_k)v_eval_k - d_k||²`，且**不把 `v_eval` 与状态动力学/实际 `nu` 混淆**。如果求解过慢，可先缓存离线构型能力近似，但必须用内层有界最小二乘核验误差。不要简单以 `sigma_min(A)` 替换该指标。

正则 `J_reg`：实际 `nu` 二范数、`nu` 变化率、`tau_a` 变化率；分别做量纲缩放后再设置权重，不要拿原 `mpc_cmg` 的舵角权重直接套用 N·m 控制输入。用于姿态误差与缺口残差的归一化尺度必须写入 YAML，并在报告中列明。

总目标：`J=J_att + lambda_cfg*J_cfg + J_reg`。初版默认**不使用构型参考轨迹**；待主项消融验证有效后，再加 `gamma_ref` 软跟踪作为独立实验臂。不要先构造第二套复杂规划器。

### 3.2 硬约束

- RK4 或统一的显式/隐式离散动力学 `x[k+1]=F(x[k],u[k],dt[k])`；时间与控制步长单位一致。
- 每个时刻 `tau_min[k] <= tau_a[k] <= tau_max[k]`（3 轴、可非对称）。
- `|nu_i|<=gdot_max`、`|nu_i[k]-nu_i[k-1]|<=gddot_max*dt`。角加速度约束**必须包含前一控制周期实际执行的 nu**。
- 框架角物理行程：原 `CMGParams` 当前未看到独立 `gamma_min/max` 字段，需检查本地配置；若未实现，**实验显式引入可配置范围**（初始试验 ±90°，仅作假设），不能默认为无限转动，也不能静默由 `sigma_floor` 代替行程限制。
- 初始状态 = 真值观测；终端四元数一致性；预测状态/控制边界误差必须单独统计。
- `tau_a` 是否设置变化率限制作为消融变量；**不要拿现有舵机 60°/s 直接当 N·m/s**，必须通过气动映射换算或不加该约束。
- 允许目标力矩不足时产生姿态跟踪误差，**不要**把 `-Aν=d` 当硬约束，也不要强制 `sigma_min > floor`。

### 3.3 求解器选型与规模控制

推荐新建 `nearspace/torque_gap_ocp.py`。第一轮采用 **CasADi + IPOPT 多重射击**（新增独立依赖，例如 `requirements-ocp.txt`；本地固定实际可用版本），模型结构对齐原 `CMGCluster`，但 CasADi 的 `A(gamma)` 需要可微等价实现：用数值差分核对 `nearspace/cmg.py` 的输出，不能直接往 CasADi 图里塞 numpy 函数。

预测时域初始方案：控制更新 `dt_ctrl=0.2 s`，非均匀预测网格 0.2 s（头 4–6 节）、0.5–1.0 s（中段）、2 s（远期），总长度按任务预告时间扩到可观察准备与机动。先做 `N≈12–24` 的可求解性扫描，再增加节点。不要宣称先天实时：记录每次求解 wall-clock、CPU、迭代数、KKT/可行性、超时与回退比例。如果全域 NLP 太慢，使用：热启动、基于上次解的解序列平移、低频重规划、控制序列分段常值；最后再考虑 SQP/RTI，而不是马上重写大规模 QP。

**求解失败策略**：保持上一条**已验证可行**的控制序列首个剩余动作（重新检查此刻气动上下限及执行机构约束）；不合法时采用受限姿态稳定保底控制；明确记录 fallback，绝不把失败求解器返回值当成正常可用解。

固定真值模型和参数，安排下面最小矩阵（单位/幅度/高度先通过可行性扫描确认，示例不是硬性性能承诺）：

| 工况 | 参考任务 | 预测气动能力 | 目的 |

## 6. 必须处理的关键工程问题

**A. 报告中要求的“提前准备”与预测窗口的关系**：若机动在预测窗口之外，`d_k=0`，优化器不会预配置。这是模型应有行为。实验 C4 必须覆盖这一点。时间网格增长时不能让 `J_cfg` 因节点数量改变而无意义放大，使用明确的时间积分权重 `dt_k`。

**B. 即时力矩能力不等于未来持续输出**：`E_k` 对每个候选 `γ` 独立最优 `v_eval`，可能在连续机动期间出现角动量积累/走入奇异区。B1 必须记录真实 `H(t), A(γ(t)), ν(t)`；若 `E` 改善但跟踪恶化，作为真实失败结论，不得隐瞒。可在后续独立实验中尝试短窗口持续能力代理，但不替换首轮固定方法。

**C. 总需求力矩的陀螺耦合项**：名义需求 `tau_nom` 的计算必须和姿态动力学使用同一 J/角速度坐标系/`H_nom`。不能再把气动固有力矩叠加两次或把机体转速与参考 Euler 角导数混用。

**D. 旧真值的一阶框架速度环**：P0 采用 11 状态即命令速率直接可达；P1 原真值有 `tau_g=0.03s`。当控制周期 0.2s 时，可分别测试无滞后/有滞后，明确预测失配，不能未经说明直接认为两者完全一致。

**E. 障碍性旧硬约束**：历史 `sigma_floor_frac`、动量预算和薄气段卸载规则属于旧控制器策略，不得未经方法文件要求直接复制进本次主优化；但真实硬件角度/速度/加速度限制必须执行。角动量范数可作为诊断和必要物理边界核验。

**F. 时间公平性与数值失败**：当前仓库历史报告中有 QP 数值发散。新求解器必须在日志中区分 NLP 真不可行、未收敛、超过时限、仿真发散、预测模型失配。不接受“自动回退后 RMSE 尚可”来替代成功率报告。

## 7. DSH 的最终验收报告格式

最终 `docs/torque_gap/experiment_report.md` 按以下顺序写：

1. **实际代码变更表**：逐文件功能与原有模块复用关系，Git commit，复现命令；如与本任务书建议路径不同，注明原因。
2. **模型验证**：`A/H/扭矩符号`、四元数、气动盒与余缺向量、P0/P1 区别，列数值误差与通过项。
3. **优化器验证**：每步 NLP 决策变量数、约束数、求解时间分布、失败/回退原因、预测与实际一致性。
4. **对照实验**：B0/B1/B2 及各 C 工况，报告原始指标表，不只报告改善率；图对应原始 CSV。
5. **机理解释**：提前迁移的开始时刻、其时气动力矩余量、CMG 迁移产生的力矩、舵面补偿、未来机动时实际输出能力；如果没有提前迁移，解释为何。
6. **结论与失败项**：明确哪一部分有效、哪一部分失败、哪些仅在 P0 虚拟力矩实验中成立；提出下一轮最小改进，**不要未经用户批准扩展一堆新算法**。

执行顺序严格为 **S0→S1→S2→S3→S4→S5**。每阶段测试不通过，停止大规模实验并先修复根因。每阶段留下 commit、可运行代码、测试记录和对应图表。若计算量大，先跑 C0/C1 最小闭环，不承诺或伪造尚未运行的全量实验结果。
