## 3. 刚体动力学

代码：`nearspace/model6c.py:86-107`

```
J ω̇ = -ω × (J ω + H_cmg(γ)) + M_aero + M_dist + M_cmg(γ, γ̇)
M_cmg = -A(γ) γ̇ ,  H_cmg(γ) = Σ_i h_i(γ) ,  A = ∂H_cmg/∂γ
J = diag(Jx, Jy, Jz) = diag(1200, 8500, 9000) kg·m²
```

与指导文件 §3.1 的形式一致：`Jω̇ + ω×(Jω) = τ_aero + τ_CMG + τ_dist` 的差别只在于
CMG 的角动量被并入陀螺项（`ω×(Jω + H_cmg)`），这是含框架动量装置的**正确**写法，
不能写成 `ω×Jω` 再加 `-Aγ̇`（那样会丢掉框架角动量带来的陀螺耦合）。

**符号独立验证（P1）**：零外矩、零气动下积分 5 s，检查惯性系总角动量
`H_in = R(q)(Jω + H_cmg)` 是否守恒。结果 `|H(t)-H(0)|/|H(0)| = 8.6e-15`。
如果把 `M_cmg = -Aγ̇` 写成 `+Aγ̇`，`Ḣ` 会多出 `-2Aγ̇` 而不守恒——所以这一项同时定住了
`-Aγ̇` 的符号和"动量并入陀螺项"两个约定。

## 4. 气动舵面

代码：`nearspace/model6.py:209-239`、`nearspace/model6c.py:76-83`

```
q_inf   = 0.5 ρ V²
α = atan2(w, u) , β = asin(v/V) , V = ||V_ned||   （V_ned 先转到机体系）
C_l = Cl_β β + Cl_p p (b/2V) + Cl_r r (b/2V) + Cl_da δa + Cl_dr δr
C_m = Cm0 + Cm_α α + Cm_q q (c̄/2V) + Cm_de δe
C_n = Cn_β β + Cn_p p (b/2V) + Cn_r r (b/2V) + Cn_da δa + Cn_dr δr
M_aero = q_inf S [b C_l, c̄ C_m, b C_n]
```

* 力矩归一化正确：滚转/偏航用翼展 `b`，俯仰用弦长 `c̄`。
* `Cm_α = -0.35 < 0` 与 `α = atan2(w,u)`（w 向下为正）一起给出静稳定性，符号自洽。
* **这是线性代理模型**：系数与 α 无关、无失速、无马赫效应、无高度相关的配平变化。
  指导文件 §3.2 要求"若只能使用简化模型必须标注为代理模型"，故在此明确标注：
  它只保证**同一模型内** A/B/C/D 四组公平，不代表真实气动。
* 舵面限制：`|δ_i| ≤ [25, 20, 20]°`，一阶伺服 `δ̇ = (δ_c - δ)/τ_s`，`τ_s = 0.05 s`，
  指令按可达集裁剪 `|δ_c - δ| ≤ τ_s δ̇_max`，因此 `|δ̇| ≤ δ̇_max = 60 °/s` 严格成立。
  P3 实测：`max|δ̇| = 0.997 rad/s ≤ 1.047 rad/s`，`|δ|max = 0.4363 rad = 25°` 恰好饱和。
* 权限量级（P7，MSIS2 f107=150，100 km，V=4000 m/s）：
  `ρ = 5.341e-7 kg/m³`，`q_inf = 4.27 Pa`，满偏 `|M_aero| = 11.56 N·m`
  （俯仰 11.28、滚转 1.95、偏航 −1.63）。与旧报告"100 km 气动权限约 11 N·m"一致，
  这条数量级是后续"仅舵面基线 A 有困难、舵面+CMG 仍可行"区域的物理依据。

## 5. 四单框架金字塔 CMG

唯一实现：`nearspace/cmg.py`（`CMGCluster`），搜索器/分配器/绘图都调用它，无第二份映射。

| 量 | 值 / 公式 | 核验 |
|---|---|---|
| 框架轴 | `g_i = [sinβ cosθ_i, sinβ sinθ_i, cosβ]`，`β = 54.7356°` | C1：`|g_i|=1`，`|g_i·g_j| = 0.333333`（理论 1/3） |
| 转子初始轴 | `s_i(0) = [-sinθ_i, cosθ_i, 0]` | C2：`s_i·g_i = 0`（精确 0） |
| 旋转后轴 | `s_i(γ) = cosγ s_i(0) + sinγ (g_i × s_i(0))` | — |
| 角动量 | `H_cmg = h0 Σ s_i(γ)`，`h0 = 50 N·m·s/单位`（簇 200 N·m·s） | — |
| 雅可比 | `A(γ) = ∂H/∂γ`，`A[:,i] = h0 (g_i × s_i(γ))` | C3：与中心差分最大差 `1.2e-7`（20 组随机构型） |
| 输出力矩 | `M_cmg = -A(γ) γ̇` | C6：`γ̇ = 0` 时力矩精确为 0；P1 间接定符号 |
| 奇异性 | `σ_min(A)`、`det(A Aᵀ)` | C5：`det(A Aᵀ) = ∏σ_i²`（相对误差 < 1e-12） |
| 家位奇异裕度 | `σ_min(A(0)) = h0·√(2/3) = 40.8248` | C4：`β = arcsin√(2/3)` 时精确成立（`40.824829046`）；配置里 `β = 54.7356°`（十进制截断）给出 `40.824839`，相对偏差 `+2.6e-7`，可忽略但**说明 `home_sigma_min` 是硬编码解析常数，不是按配置 β 现算的** |
| 保证力矩 | `σ_min·γ̇_max = 40.8248 × 1.5 = 61.24 N·m`（最坏方向） | C4；与 `mpc_cmg.M_cmg_box = 61.0` 一致 |
| 峰值力矩 | 最优方向 `max_‖u‖≤1 ‖A u‖ · γ̇_max = 244.95 N·m` | C5/C7：峰值远大于保证值，说明"只用 σ_min 判断能力"会低估，也说明能力必须按方向评估（指导文件 §5.4 的要求） |
| 单机细节 | 转子 6000 rpm，`J_r = h0/Ω = 0.0796 kg·m²`，30 kg/机，200 W/机 | 由 `h0` 与转速**反推**，非实测 |

**建模范围声明**：转子转速恒定（无转速环动态、无内部角动量漂移）、框架驱动为一阶惯性
`τ_g = 0.03 s`、无摩擦、无框架角行程（见 §7 G2）。指导文件 §3.3 明确要求"若模型含转子
转速变化、框架驱动动态或摩擦，分别建模"——本模型**不含**前两者与摩擦，故新实验中若引入
必须另行建模，不能悄悄混入。

## 6. 参考指令与底层周期

* 五次多项式 `r(s) = 10s³ − 15s⁴ + 6s⁵`（`s = (t−t0)/Tm` 截断到 [0,1]），
  与指导文件 §4.1 完全一致：`nearspace/trajectory3.py:80`。
  端点速率/加速度为零，峰值速率系数 1.875、峰值加速度系数 5.773503（`Tm=20 s`、

  积分步 `dt_plant = 0.005 s`（40 倍细分，RK4）。

## 8. 结论与对后续阶段的约束

1. 旧模型的**符号与几何自洽**：`M_cmg = -A(γ)γ̇`、CMG 角动量并入陀螺项、`R_dot = R[ω]×`、
   金字塔几何与 `σ_min(A(0)) = h0√(2/3)` 均可独立复现。
2. 旧模型的**数量级可用**：100 km、4 km/s 时气动权限 11.56 N·m，CMG 保证力矩 61.24 N·m、
   峰值 244.95 N·m，簇角动量 200 N·m·s——这是"气动不够、CMG 补上"的量化依据。
3. 旧模型的**能力边界必须由 G1/G2 决定**：框架角加速度与行程是硬约束还是名义值，直接决定
   构型图的规模与边的可行性。**这两项在写构型搜索之前必须先定**，否则图是建在假设上的。
4. 新实验**不 import** `nearspace/`：上面的检查是给新实现的对照表，新实现要从
   `experiments/cmg_incremental_search/src/` 里独立重写并在自己的单元测试里重跑同构检查
   （指导文件 §3.5 的六项测试）。
