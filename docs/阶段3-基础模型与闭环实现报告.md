## 3. 实施过程中发现并修正的问题（如实记录）

1. **姿态误差符号写反**。`e = 2·dq_vec(q_ref⁻¹⊗q)` 是"参考→机体"的旋转矢量，纠偏力矩必须取
   `-J(k_att e + k_rate ω_err)`。初版写成 `+J(...)`，闭环误差指数增长到 **179°**、请求力矩打满
   1000 N·m 上限。修正后同一初值收敛到 `0.001°`。此结论已写进
   `src/control/attitude_controller.py` 的文档串，禁止再"顺手"改符号。
2. **分配器漏掉气动配正常数项**。`M_aero` 里与 `δ` 无关的状态相关部分（α、β、角速度项）
   必须作为常数进入 QP，否则"预测力矩"系统性偏低（实测 `0.69 N·m`）。现在
   `M_aero0 + B_δδ - Aγ̇` 与 plant 完全同一来源，T4 的差值降到 `0.0`。
3. **安全回退的残差口径**。初版回退把 `residual` 相对**缩放后**的请求计算，日志显示"残差 0"
   而实际缺 50%，会掩盖能力不足。现在残差一律相对**原始** `τ_req` 报告，另记
   `fallback_scale` 与 `scaled_feasible`。
4. **PD 增益必须与实际权限匹配**。100 km 处 CMG 保证力矩 61 N·m、气动约 11 N·m；
   旧设定 `k_att=0.6, k_rate=1.6` 在 1° 误差时就要 89 N·m，必然持续饱和。现为
   `0.15 / 0.55`（ωₙ≈0.39 rad/s、ζ≈0.71），1° 误差只需 22 N·m。
5. **日志口径**。增加 `request_feasible`（原始请求是否可实现）与 `tau_effective`
   （由角动量方程反解的等效平均力矩），避免用"回退后可行"冒充"请求可行"。

## 4. 已知缺陷与遗留风险

| 编号 | 问题 | 影响 / 计划 |
|---|---|---|
| S1 | 基础控制器**没有构型回中**（λ_γ 只压 `γ̇→0`），框架角在 3° 机动中漂到 57° | 这正是 C/D 组搜索要解决的问题；B 组保持"无迁移参考"以便公平对照，阶段 7 会量化框架角漂移与 σ_min 恶化 |
| S2 | 分配器无动量管理（`H_cmg` 软约束），仅由 `γ̇` 正则间接抑制 | 阶段 5 接入搜索参考前先量化；若动量累积到 σ 地板则必须加约束并如实报告 |
| S3 | 力矩按"瞬时口径"与"等效平均口径"分别记录，两者差 `0.021 N·m`（1 步爬升） | 指标表会同时给出两个口径，不选一个"好看"的 |
| S4 | 单场景仅 3° 俯仰机动 | 幅度本身待阶段 7 可行性扫描决定，当前数值不是结论 |
| S5 | 气动仍是线性代理、惯量无出处 | 已在阶段 1 定案：只报告同一模型内的相对结论 |
| S6 | 未做多初始构型与随机种子配对 | 属阶段 8 要求 |
