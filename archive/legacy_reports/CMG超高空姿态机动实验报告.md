# 超高空姿态机动下 CMG 辅助统一 MPC 实验报告

> **本版变更（相对上一版）：** 按要求把参考姿态从"五次多项式斜坡"改成**阶跃**（在 t0 时刻直接跳到
> θ0+Δθ 并保持），因此"机动完成时间"不再被参考斜坡卡住，成为真正的评价指标。
> 五次多项式斜坡的全部结果保留在 **附录 A**（数据未被覆盖），两套结果可以直接对照。

**研究问题：** 在约 100 km、气动舵面权限下降时，CMG 能否改善有限时长姿态机动的
完成时间、跟踪精度与执行机构负担？

**结论（先给结论）：**

1. **只有 5° 阶跃上 CMG 是正收益**：A 完成 7.6 s，B 完成 **6.8 s**（快 0.8 s），窗口 RMSE
   1.002° → **0.890°**（−11.2 %），峰值 3.75° → 3.51°，舵面饱和 0 %，|H| 峰值 13.71 N·m·s
   （预算 60），**QP 回退 0 步**。这是全部工况里唯一"B 既更快又更准、且执行机构与求解器都没问题"
   的工况。
2. **10° 与 15° 阶跃上 CMG 是负向的**：A 分别用 13.4 s / 18.2 s 完成（峰值 8.71° / 13.71°），
   而 **B 直接发散**（窗口 RMSE 91.3° / 89.5°，峰值 179.9° / 178.7°，窗口内 100 % 时间处于
   保底控制器，|H| 92.3 / 64.6 N·m·s，σ_min 4.31 / 2.14，最大约束违反量 3.3e11）。
3. **发散的直接机理是控制器"提前看到"阶跃，不是物理能力不够**：预测时域 7.2 s，
   |H|、σ 都还在限内时 QP 就已经开始回退——首次回退比阶跃早 **6.0–6.6 s**。
   把同一个 10° 阶跃从 t0=118 s 推迟到 125 s，首次回退从 111.6 s 推迟到 **119.0 s**，
   提前量不变 → 复现了"预瞄不连续参考导致 QP 失效"这一条。
   一旦进入保底，CMG 一边充电、一边丢失奇异余量，|H| 越过预算后锁死，误差发散。
4. **物理背景同样存在**：阶跃要求的是**持续**力矩，CMG 必须把角冲量存起来
   （10° 阶跃 J·ω ≈ 140 N·m·s ≈ 2.3 × 60 N·m·s 预算）；气动舵面则把动量直接还给大气，
   不需要储存。所以即使修好预瞄逻辑，10°/15° 阶跃对 60 N·m·s 的 CMG 仍然吃力，
   而 A 不受这条限制——这与之前 C1 诊断实验的结论（CMG 是动量储存器、气动是动量汇）一致。
5. **B 的求解时间在能完成的工况上仍然超标**：5° 时 P95 = 321 ms（A 为 164 ms），
   超过 200 ms 控制周期。按方案 §9，"姿态更好但违反实时性要求"不能声称可部署的控制优势。

### 1.1 阶跃参考的实现（以及为什么需要额外一条规则）

* `nearspace/trajectory3.py::Maneuver.value` 新增 `shape="step"`：t < t0 返回 0，t ≥ t0 返回 Δθ。
* 阶跃参考在 t0 **不可导**。若沿用"参考角速度 = 参考姿态的有限差分"，t0 处会出现
  一个 ~Δθ/0.001 s 的伪角速度尖峰（10° 时约 175 rad/s），MPC 会在该节点被这个不可达
  的参考拖饱和。因此 `omega_ref` 增加一条规则：**把阶跃偏置冻结在它在该时刻的取值，
  只对平滑部分（航迹角/航向）求导**——即"把新姿态稳住"的参考角速度为 0。
* 回归验证：对五次多项式工况，改动前后 `q_ref / omega_ref / pitch_ref` 在 9 个采样点
  **逐位相同**（`omega_ref(118.0) = [0, −0.00677351, 0]`），即斜坡行为未被改变。

### 1.2 A/B 差异（逐项断言，`task_parity.json`）

只有 `/actuators/mode`、`/mpc_cmg/M_cmg_box`、两个显示标签；参考姿态逐点相同（差 0.0）、
初值相同、扰动全程为 0。A 组在真值模型里 `cmg_on = False`、控制器 `M_cmg_box = 0`：
三组 A 运行里 `max|H| = max|框架角| = max|框架速率| = max|M_cmg| = 0`（精确 0）。
阶跃参考的专项校验：t0 前为 0、t0 起为 Δθ 并保持；t0 处参考角速度有限
（0.00677 rad/s，只有航迹角分量）。

## 2. 阶段 B：可行性

### 2.1 阶跃参考的物理下界（`maneuver_step_feasibility.csv`）

阶跃没有斜坡，方案 §4 里"参考角速度/角加速度连续"不再适用；换成更有意义的物理问题：
**用满偏气动权限（或 气动 + CMG 力矩盒）做 bang-bang 加速-减速，把一个 Δθ 搬完要多久**：

  α = M_max/J_y， T = 2√(Δθ/α)， ω_peak = αT/2

| h [km] | Δθ | 气动上限 | α_A [°/s²] | T_min_A [s] | α_B [°/s²] | T_min_B [s] | J·ω_B / 预算 |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 90 | 5° | 99.7 N·m | 0.672 | 5.45 | 1.001 | 4.47 | 5.53 |
| 100 | 5° | 20.3 N·m | 0.137 | 12.10 | 0.364 | 6.55 | 3.77 |
| 100 | 10° | 20.3 N·m | 0.137 | 17.11 | 0.364 | 9.27 | 5.33 |
| 100 | 15° | 20.3 N·m | 0.137 | 20.96 | 0.364 | 11.35 | 6.53 |
| 110 | 5° | 3.5 N·m | 0.023 | 29.30 | 0.249 | 7.54 | 3.28 |
| 110 | 10° | 3.5 N·m | 0.023 | 41.44 | 0.249 | 10.66 | 4.64 |

读法（重要）：
* 这是**乐观下界**：忽略 Cm_q 气动阻尼、配平攻角、气动权限随动压变化，也没有考虑
  "只要进入 ±1° 带即可完成"这件事，所以实测完成时间可以比它短（M1-A 实测 7.6 s < 12.10 s，
  因为初始误差已经是 −1.18°，实际只需转过约 2.8° 就进入 ±1° 带）。
* `J·ω_B / 预算` 是"若全部由 CMG 承担"所需的角动量 ≡ 3.3–6.5 倍控制器预算。
  也就是说：**阶跃对 CMG 来说本来就是超预算的任务**，它的正收益空间只能来自
  "用 CMG 抢前 1–2 s 的瞬态、其余交给气动"。

## 4. 失效机理：控制器"提前看到"阶跃

| 证据 | 数据 |
|---|---|
| 预测时域长度 | 6×0.2 + 4×0.5 + 4×1.0 = **7.2 s** |
| 10° 阶跃（t0=118 s）首次 QP 回退 | **111.6 s**（比阶跃早 **6.4 s**），此后连续 433 步 |
| 15° 阶跃（t0=118 s）首次 QP 回退 | **111.4 s**（早 6.6 s），连续 428 步 |
| 5° 阶跃（t0=118 s）首次 QP 回退 | **无**（0 步） |
| **诊断臂**：同一 10° 阶跃推迟到 t0=125 s | 首次回退 **119.0 s**（仍提前 6.0 s） |
| 首次回退时的状态（10°/15°，t≈111 s） | \|H\| = 2.5 / 1.7 N·m·s、σ_min ≈ 34 / 30 → **都远在限内** |
| 之后 | σ 在 114.6 / 115.6 s 跌破下限，\|H\| 在 115.8 / 116.0 s 越过预算，误差持续发散 |

机制链条：

1. t ≈ 110.8 s 起，7.2 s 的预测时域开始包含 t0 处的阶跃，参考姿态在时域内"跳"了 Δθ；
2. MPC 试图在短时间内预置姿态 → 预测框架角速度接近限幅 → 预测 σ_min 逼近甚至穿过
   1.15×下限（奇异约束**没有松弛变量**）→ 该行不可行 / 返回解违反量 > 1e−3 → 判失败；
3. 一旦进入保底（`failsafe`：速率阻尼 + 按其自身规则用 CMG），闭环里 CMG 不再受
   统一 MPC 的动量规划，开始持续充电；薄气段又禁止卸载，于是 \|H\| 单调增长；
4. \|H\| 越过 60 N·m·s 后，`momentum_box` 与 `no_unload_thin_air` 互相矛盾
   （这是 C1 诊断实验 E3 已经定位过的同一条死锁），QP 永久不可行 → 整窗保底 → 发散。

**结论：** 阶跃工况下 B 的失败首先是**控制器缺陷**（对不连续参考的预瞄处理：没有在参考跳变
前后限制预测需求，也没有给奇异约束留松弛），其次才是**物理限制**（阶跃要求的持续角冲量
超过 CMG 的 60 N·m·s 预算 2–3 倍）。A 之所以不受影响，是因为气动舵面把动量直接还给大气，
不需要储存——它的限制是力矩权限（20.3 N·m @100 km），而这个限制在 5–15° 阶跃里都能满足。

## 5. 判定（方案 §9）

| 工况 | 完成时间 | 精度 | CMG 约束 | 实时性 | 判定 |
|---|---|---|---|---|---|
| M1 5° 阶跃 | **B 快 0.8 s** | B 好 11 % | 满足（\|H\| 23 % 预算、σ 38.6） | P95 321 ms，超周期 | 有收益，**不可部署** |
| M2 10° 阶跃 | A 完成 / **B 未完成** | B 差 32 倍 | **不满足**（\|H\| 92 > 60、σ 4.3 < 12.25） | 全程回退 | **负向结果** |
| M3 15° 阶跃 | A 完成 / **B 未完成** | B 差 17 倍 | **不满足**（\|H\| 64.6 > 60、σ 2.1） | 全程回退 | **负向结果** |

**综合判定：**
* 与斜坡版本（附录 A）相比，**阶跃把结论反过来了**：斜坡时 CMG 在 5°/10°/15° 上都能改善精度
  （−9 %/−19 %/−32 %），阶跃时只在 5° 上改善（−11 %），10° 起直接发散。
* 原因是物理与控制器叠加：阶跃要求持续大角冲量（超出 CMG 预算 2–3 倍），而当前 MPC 的
  预瞄 + 无松弛奇异约束会在阶跃到来前 6 s 就把 QP 逼到不可行。
* 因此**不能**用本实验声称"CMG 适合超高空姿态机动"；能说的只有：
  **在 5° 量级的阶跃上 CMG 有 0.8 s / 11 % 的收益，10° 以上在当前控制器下不可用。**

## 8. 限制

1. 单次运行，无 Monte-Carlo。
2. 阶跃参考使 t0 处 C¹ 不连续；方案 §3.2 原本要求限速参考，本次改动是按要求做的，
   相关后果（预瞄失效）已在 §4 定量说明。
3. 阶跃工况的"完成判据"从 t0 起算，因此初始误差（约 −1.2°，A 组实测）会计入，
   M1-A 的 7.6 s 比"搬完 5°"的理论下界 12.10 s 短就是这个原因。
4. 未做：参考跳变前后的"阶跃预览处理"（例如把参考在时域内做一次斜坡化、或给奇异约束加松弛）、
   M4 三轴耦合 / M5 高度扫描 / M6 瞬态扰动。
5. B 的实时性未解决：能正常求解的 M1-B 上 P95 = 321 ms、最坏 379 ms（A 为 164 / 217 ms）；
   发散工况（M2/M3-B）的 P95 反而只有 97–137 ms，因为绝大部分步直接走保底、没有真正求解。
   即"求解时间看起来变好"在发散工况上是假象，报告不把它当作实时性改善。
