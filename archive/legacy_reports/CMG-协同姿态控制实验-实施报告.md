## 1. 结论先行

1. **CMG 的收益是真实的，但只出现在"瞬态受限"窗口内，幅度 9%–15%。**
   - 100 km 顶点 120 N·m·s 俯仰脉冲：三轴 RMSE 0.2270° → **0.2056°（−9.4%）**，
     峰值 0.8148° → **0.7185°（−11.8%）**，升降舵峰值 14.75° → 13.57°。
   - 100 km 顶点 10° 俯仰机动（Tm = 20 s）：RMSE 0.5476° → **0.4655°（−15.0%）**，
     峰值 2.531° → **2.144°（−15.3%）**，机动完成时间 20.6 s → **20.2 s**，
     舵面饱和时间比例 2.70% → **0**。
2. **CMG 在气动权限充足时毫无作用，且不会造成恶化。**
   - 名义三轴跟踪：RMSE 0.04914° → 0.04890°（−0.5%），峰值完全相同；
     CMG 峰值力矩仅 0.053 N·m、峰值角动量 0.60 N·m·s（预算的 1%）。
   - 90 km 顶点同一 10° 机动：RMSE 0.1658° → 0.1656°（−0.1%），
     CMG 峰值力矩 0.11 N·m。**气动在这个高度本来就够用。**
3. **在能力边界上，B 不只是"没有优势"，而是会失败得更惨。**
   - 100 km 20° 机动（Tm = 20 s）：A 完成（25.4 s，峰值 9.30°）；
     **B 发散**（RMSE 41.1°、峰值 179°、角动量冲到 77.1 N·m·s 超出 60 N·m·s 预算、
     σ_min 掉到 13.8、框架速率打满 1.5 rad/s、约束违反量 3.1e11）。
   - 115 km 10° 机动：A 未完成（峰值 4.19°、舵面饱和 36.6% 的时间）；
     **B 同样发散**（峰值 143°、σ_min 掉到 **1.02**、违反量 3.1e11）。
   - 这与可行性检查（§4）的预判一致：这两个任务对 B 而言冲量需求已超过
     "气动能力 + 控制器动量预算"之和。
4. **B 的代价是明确的、可量化的：** 舵面平均动作量增加 1.8–2.3 倍（高频抖动），
   单步求解时间增加约 1.6–2.2 倍（平均 A 299–444 ms / B 514–818 ms）。
5. **因此正确的表述是：** 在 89–100 km、以瞬态扰动抑制为主的任务里，
   CMG 能把误差降 ~10%–15%、并显著减轻舵面饱和；它不能替代动量汇，
   一旦任务冲量需求超出"气动 + 动量预算"，CMG 会先饱和、再在无阻尼轴上留下
   反作用，使结果比纯舵面更差。**本阶段不声称"CMG 全程更好"。**

## 2. 实验设置

### 2.1 两种方案

| | A `surface_only` | B `surface_cmg` |
|---|---|---|
| 执行机构 | 仅 3 个气动舵面 | 3 个气动舵面 + 4 单元单框架 CMG 金字塔 |
| MPC 决策量 | `[δ_c(3)]`（CMG 力矩盒 = 0） | `[δ_c(3), M_cmg(3)]` 联合优化 |
| 真值模型 | 18 状态但 `cmg_on = False`：框架冻结、`M_cmg≡0`、`H≡0` | 18 状态全开 |

**A 不是"有 CMG 但不用"**：`VehicleCMGParams.cmg_on = False` 在真值动力学里
把 CMG 力矩项与陀螺项都置零、框架角与框架速率都冻结（home 位形净角动量为零），
因此 A 是一架真的没有 CMG 的飞行器。

### 2.2 公平性（§3.3）

`configs/cmg_ab/matrix.yaml` 的 `common` 块唯一给出环境、弹道、参考、控制器权重；
`modes` 块唯一给出执行机构。解析后的 A/B 配置**只差 3 处**
（`actuators.mode`、`mpc_cmg.M_cmg_box`、显示标签），由
`tests/test_cmg_ab.py::test_fairness` 每次自动断言。其余完全相同：

* 高度剖面 30 → 顶点 → 下降（余弦跳跃，顶点 t = 120 s）；
* 速度 V(t) = 4000 − 4t m/s；
* **NRLMSIS-2.0** 大气（F10.7 = 150, Ap = 4, 45°N），查表缓存；
* 同一套线性示例气动系数；
* 同一初始状态：四元数取参考姿态，角速度为零，
  升降舵取气动配平值 `δe = −Cm_α/Cm_δe·(θ_ref − γ)`；
* `dt_ctrl = 0.2 s`、`dt_plant = 0.005 s`、RK4、同一积分器；
* 同一套指标定义与**运行前固定**的评分容差（见 2.4）。

### 2.3 工况表

| 工况 | 高度顶点 | 任务 | 仿真时长 | 用途 |
|---|---|---|---|---|
| `tracking` | 100 km | 无扰动、无指令机动的三轴跟踪 | 150 s | E1-A |
| `disturbance` | 100 km | 112 s 起 80 N·m 俯仰脉冲 1.5 s（120 N·m·s） | 145 s | E1-B（复用项目既有工况） |
| `disturbance3` | 100 km | 112 s 起三轴耦合脉冲 (12, 80, 20) N·m 1.5 s | 145 s | E1-B2 |
| `maneuver10` | 100 km | 118 s 起 10° 俯仰五次多项式机动，Tm = 20 s，之后保持 | 170 s | E2 |
| `maneuver20` | 100 km | 同上，20° | 170 s | E2（能力边界） |
| `h90_maneuver10` | 90 km | 同 `maneuver10` | 170 s | E3-90 |
| `h115_maneuver10` | 115 km | 同 `maneuver10` | 170 s | E3-115（边界/局限） |

参考机动用方案 §5.3 的五次多项式
`θ_ref = θ0 + Δθ·(10s³ − 15s⁴ + 6s⁵)`，`s = clip((t−t0)/Tm, 0, 1)`，
峰值角速度 `1.875Δθ/Tm`、峰值角加速度 `5.7735Δθ/Tm²` 由
`nearspace/scenarios.maneuver_demand()` 逐工况打印。

### 2.4 评分常数（运行前固定，写入每次运行的 `meta.json`）

| 量 | 值 |
|---|---|
| 扰动后恢复的绝对容差带 | 0.05°（另报 10% 峰值带的相对口径） |
| 保持时长（恢复） | 2.0 s |
| 机动完成容差带 | max(0.5°, 5%·\|Δθ\|) |
| 保持时长（机动） | 3.0 s，从参考轨迹**结束时刻**起算 |
| 机动后观察窗 | 20 s |
| 舵面饱和判据 | \|δ\| ≥ 0.999·δ_max |
| QP 成功判据 | 最大约束违反量 ≤ 1e-3（不看 OSQP 状态字符串） |
| 未进入容差带 | 记为 **未完成**，不给有限时间值 |

机动完成时间之所以从参考轨迹**结束**时刻起算，是因为俯仰参考角
`θ_ref = γ(t) + α_trim + Δθ·s(t)` 在机动结束后仍随航迹倾角 γ 变化，
"冻结的最终姿态"不是一个有效目标；从参考结束时刻起算再要求保持 3 s，
等价于"完成重定向并且已经跟住新参考"。

## 3. §7 专项核验（结论摘要，详见 `docs/CMG-权重与动量约束核验.md`）

| 项 | 结论 |
|---|---|
| 风险 A：`r_cmg_transient = r_cmg_trim = 0.5` | **确认存在**。两值相等使误差自适应切换失效，CMG 全程被 0.5 惩罚，首步 CMG 力矩只被允许 2.80 N·m（61 N·m 权限的 4.6%）。冻结值改为 **0.05 / 0.5**。 |
| 权重是否真的进目标函数 | 是：`r_cmg` 0.5 → 5e-4 时，首步最优 `\|M_cmg\|` 从 2.80 单调升到 29.52 N·m。 |
| 力矩链路 | 常值 20 N·m 指令下 0.5–2.5 s 交付 19.3–19.9 N·m（96%–99.6%）；3 s 后因穿越奇异面交付跌到 0。 |
| 硬件 vs 控制器预算 | 硬件：集群 200 N·m·s、全向保证力矩 **86.77 N·m**、单轴可用角动量 **107.74 N·m·s**；控制器：`M_cmg_box` 61 N·m、动量预算 60 N·m·s。两者分别核算，未混用。 |
| A 方案是否真的没有 CMG 力矩 | 是，且在真值模型中断开。 |

## 4. §5.2 机动可行性检查（先检查，后跑）

`python scripts/check_maneuver_feasibility.py`，原始表
`results/cmg_ab/maneuver_feasibility.csv`。判据：需求峰值力矩与半程冲量，
分别对比"气动上限"与"气动上限 + 控制器动量预算"，需求 > 115% 能力判 infeasible。

100 km 顶点、V = 3528 m/s、气动最大俯仰力矩 **20.27 N·m**：

| Δθ | Tm | 需求峰值力矩 | 需求半程冲量 | A 判定 | B 力矩上限 | B 冲量上限 | B 判定 |
|---|---|---|---|---|---|---|---|
| 10° | 15 s | 38.07 N·m | 185.4 N·m·s | infeasible | 69.07 N·m | 212.0 N·m·s | marginal |
| **10°** | **20 s** | **21.41 N·m** | **139.1 N·m·s** | **marginal** | **69.07 N·m** | **262.7 N·m·s** | **feasible** |
| 20° | 20 s | 42.83 N·m | 278.2 N·m·s | infeasible | 69.07 N·m | 262.7 N·m·s | marginal |

90 km：气动上限 99.71 N·m，10°/20 s 对 A、B 都是 feasible（→ 预期无差异，实测证实）。
115 km：气动上限仅 **1.48 N·m**，10°/20 s 对 A infeasible；B 冲量上限 74.8 N·m·s
< 需求 139.1 N·m·s，**同样 infeasible**（→ 预期同为失败边界，实测证实）。

**这解释了为什么把 10° 的 Tm 定为 20 s**：这是唯一一个"A 边际、B 充裕"的点，
能把 CMG 的贡献与其他因素分开。方案里 2–5 s 的候选值在本模型下全部不可实现
（10°/2 s 需要 2141 N·m，是气动上限的 106 倍），因此不采用。

| 姿态误差峰值 | 2.531° | **2.144°** | **−15.3%** |
| 机动窗峰值 | 2.531° | **2.144°** | −15.3% |
| 机动完成时间 | 20.6 s | **20.2 s** | −0.4 s |
| 机动后 20 s 保持 RMSE | 0.3546° | 0.3591° | +1.3%（基本持平） |
| 俯仰最大超调 | 0.574° | 0.589° | +2.7% |
| 升降舵峰值 | 25.0°（**饱和**） | **23.0°** | 脱离饱和 |
| 舵面饱和时间比例 | 2.70% | **0** | 消除 |
| 舵面平均动作量 | 0.1424 °/步 | 0.2541 °/步 | +78% |
| CMG 峰值力矩 / 角动量 | 0 | 6.70 N·m / 19.08 N·m·s | 预算的 32% |
| σ_min | 40.82 | 38.52 | 安全 |
| QP 失败 / 回退 | 0 / 0 | 0 / 0 | — |

**读数：** 这是本轮最干净的正向结果：**舵面从饱和（25°，2.7% 时间）退到 23°、
饱和完全消除**，同时误差峰值降 15%、完成时间略快、机动后保持精度不变、
动量只用掉 32%。机理由图 `figures/cmg_ab/maneuver10_maneuver.png` 第 6–7 行
直接给出：118–138 s 期间 CMG 提供峰值 6.7 N·m，`|H|` 单调涨到 19 N·m·s，
机动结束后由气动在 20 s 内缓慢卸载回零。

方案 §5.2 把"执行机构可行性边界差异"和"跟踪精度比较"分开，本工况属于后者
（A 边际可行、B 充分可行）。

### 6.2 20° / Tm = 20 s（`maneuver20`）——B 失败，且必须如实报告

| 指标 | A | B |
|---|---|---|
| 三轴 RMSE | **2.140°** | 41.06° |
| 姿态误差峰值 | **9.303°** | 179.0° |
| 机动完成时间 | **25.4 s** | **未完成** |
| 机动后保持 RMSE | **1.848°** | 78.54° |
| 舵面饱和时间比例 | 9.87% | 26.56% |
| CMG 峰值力矩 | 0 | **99.77 N·m**（超过 61 N·m 指令盒） |
| CMG 峰值角动量 | 0 | **77.13 N·m·s**（超出 60 N·m·s 预算、未超 107.7 硬件单轴极限） |
| 框架速率峰值 | — | **1.5 rad/s（打满）** |
| σ_min | 40.82 | **13.84**（下限 12.25） |
| 约束违反量 | 3.55e-05 | **3.12e+11** |
| QP 失败 / 保底触发 | 0 / 0 | **219 / 219**（最长连续 214 步） |
| QP 未正常收敛步数 | 9 / 851 | **230 / 851** |

**机理（图 `maneuver20_maneuver.png` 一图说完）：**

1. 118 s 起参考要求 42.8 N·m 峰值力矩，而气动只有 20.3 N·m → 两方案的升降舵都打到 −25°；
2. B 的 CMG 先给出 ±50 N·m 量级的补偿，`|H|` 在约 6 s 内从 0 涨到 **60 N·m·s 预算上限**
   （第 7 行曲线在 60 处出现平台——径向包络 `H·M_cmg ≥ (|H|²−H_lim²)/(2Δt)` 正在起作用）；
3. 与此同时 σ_min 从 38.5 掉到 13.8，框架角被推到 ±180°，框架速率打满 1.5 rad/s；
4. 动量用完后 CMG 无法再提供力矩，而它在滚转/俯仰轴上留下的反作用必须由气动还回去，
   此时气动本身已在饱和，于是误差单调发散到 −45°；
5. 到 168 s 以后气动权限回升，B 才开始收敛，但已无法在观察窗内完成。

**这不是调参能解决的**（与 `docs/CMG-实现状态.md` §10.7 的工程结论一致）：
CMG 是动量交换装置而不是动量汇。20°/20 s 所需的半程冲量 278 N·m·s
超过"气动 20.3 N·m × 10 s + 预算 60 N·m·s = 263 N·m·s"，
可行性检查事先就把它判成 marginal——实测比预估更糟，因为
近奇异区的"指令力矩 ≠ 交付力矩"还会额外损失能力。

## 9. §10.4 判据逐条核查——什么结果支持"CMG 有效"

| 判据 | 100 km 扰动 | 100 km 10° 机动 | 100 km 20° 机动 | 115 km 10° 机动 |
|---|---|---|---|---|
| 1. B 姿态指标明确改善，或 A 不能完成的合理任务 B 能完成 | ✅ −9.4% / −11.8% | ✅ −15.0% / −15.3% | ❌ B 发散 | ❌ 双方失败 |
| 2. B 没有通过违反硬件限制获得改善 | ✅ \|H\|max 7.8 ≪ 60 | ✅ 19.1 ≪ 60，σ_min 38.5 | ❌ 指令/交付力矩 99.8 N·m、σ_min 13.8 | ❌ σ_min 1.02 |
| 3. QP 失败与回退没有严重恶化 | ✅ 0 / 0 | ✅ 0 / 0 | ❌ 219 步回退、最长连续 214 步，违反量 3e11 | ❌ 280 步回退、最长连续 280 步，违反量 3e11 |
| 4. 角动量未在观察窗内失控积累 | ✅ 回到 ~0 | ✅ 单调卸载 | ❌ 撞上 60 N·m·s 平台后无法还回 | ❌ 同上 |
| 5. 改善在多个任务中一致 | ✅ 三个扰动/机动工况一致 | | | |
| 6. 机理图能解释改善来自 CMG 实际力矩 | ✅ 图 6–7 行 | ✅ 同时舵面饱和消失 | ❌ | ❌ |

**可以下的结论：**

* 在 89–100 km 的**瞬态受限**任务里（脉冲扰动、10° 级机动），
  CMG 有**一致、可解释、代价可量化**的正收益（误差 −9%~−15%、舵面饱和减少或消除）；
* 在 90 km 及以下，CMG 无收益也无害；
* 在冲量需求超过"气动 + 动量预算"的任务里（20° 机动、115 km 机动），
  CMG **会让结果比纯舵面更差**，因为它是动量交换装置而不是动量汇；
* 因此方案 §1.3 的立场成立：**本阶段不声称"CMG 一定更好"**，
  而是给出"CMG 在什么条件下更好、在什么条件下更差"的定量边界。

## 11. 已知粗糙处与下一步

1. **B 的舵面与 CMG 力矩存在高频抖振。** 目标函数里没有 CMG 力矩的速率惩罚项
   （`J_smooth` 只作用于舵面），`r_cmg` 也只约束幅值。表现为舵面平均动作量
   A 的 1.8–2.3 倍、CMG 力矩每步变号。下一步应加入
   `Σ‖M_cmg,k − M_cmg,k−1‖²` 与框架速率惩罚，再评估收益是否保持。
2. **求解时间不满足实时。** 单步均值 A 299–444 ms / B 514–818 ms，
   而 `dt_ctrl = 0.2 s`。在"持续 1° 姿态误差"这一最坏节点上单进程实测
   B 为 1211 ms/步（P95 1295 ms）。主要开销是
   14 个预测节点 × 24 次有限差分扰动 × 2 次 SQP ≈ 672 次非线性模型求值/步，
   与是否含 CMG 关系不大（A 一样慢）。
   下一步：解析 Jacobian、改前向差分、减 SQP 迭代，或降低预测节点数。
3. **近奇异区"指令力矩 ≠ 交付力矩"。** 20° 机动里 CMG 峰值交付 99.8 N·m
   而指令盒是 61 N·m，说明阻尼伪逆在 σ_min 崩落时会放大偏差。
   这与 `docs/CMG-实现状态.md` §4 记录的因果链一致，仍未根治。
4. **没有动量汇。** 本阶段不含 RCS，因此 89 km 以上的长期动量管理仍然无解；
   115 km 的失败就是这一事实的直接后果。
5. **气动系数仍是线性示例值**，所有"气动权限"结论只在本模型内成立。
6. **单次运行、无重复试验。** 仿真完全确定（无随机因素），因此未做配对种子重复；
   若后续引入随机场景，需按方案 §10.3 重做。
7. **权重在扰动工况上选定。** 若以机动工况调参，B 的最优 `r_cmg` 可能不同；
   本报告按方案要求做了调参/验证集分离，但只扫描了 4 个值。
