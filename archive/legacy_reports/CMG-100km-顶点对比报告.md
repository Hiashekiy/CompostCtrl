# CMG 对比实验报告：100 km 顶点、120 N·m·s 俯仰脉冲

> 配图：`results/cmg_compare.png`
> 数据：`results/cmp_A.csv`（仅舵面）、`results/cmp_B.csv`（舵面 + CMG）
> 复现：`config.yaml` 当前即本算例；`python run_cmg_compare.py A|B 145` 然后
> `python make_cmg_compare_figure.py`。图中所有数字由脚本从 CSV 与 config 自动读取，
> 不存在手工填写导致的漂移。

---

## 1. 算例定义

| 项 | 取值 |
|---|---|
| 高度剖面 | 跳跃滑翔，起始 30 km，振幅 70 km，周期 240 s → **顶点 100 km 在 t = 120 s** |
| 速度 | V₀ = 4000 m/s，dV/dt = 4 m/s² |
| 大气 | NRLMSIS-2.0（`pymsis`，F10.7 = 150，Ap = 4） |
| 扰动 | **80 N·m 俯仰脉冲 × 1.5 s，t = 112.0 s 起 → 120 N·m·s** |
| 该处气动权限 | 最大俯仰力矩 **11.3 N·m**（仅为脉冲幅值的 14 %） |
| CMG | 4 × 50 N·m·s 单框架金字塔；全向保证力矩 86.7 N·m（保守下界 61.2 N·m）；硬动量预算 60 N·m·s |
| 控制器 | 统一 MPC，14 节点 / 7.2 s 时域，dt_ctrl = 0.2 s，dt_plant = 0.005 s |
| A / B | A = 仅舵面（`M_cmg_box = 1e-6`）；B = 舵面 + CMG。**其余配置完全相同** |
| 时长 | 145 s（725 个控制步） |

选这个高度和这个脉冲量是有意的：脉冲幅值 80 N·m 远超人控权限 11.3 N·m，
但又不足以打爆 CMG 的 60 N·m·s 预算——正好落在"CMG 该不该出力"的判别区间里。

---

## 2. 六个面板逐条解读

### ① 三轴姿态误差范数（全程）
| | RMSE | 峰值 |
|---|---|---|
| A 仅舵面 | 0.2297° | 0.818° |
| B 舵面+CMG | **0.2201°** | **0.768°** |

B 的曲线整体压在 A 下面。误差由两段构成：112–113.5 s 的脉冲尖峰（约 0.36°）
和 115–140 s 的恢复鼓包（峰值约 0.8°，是全run 最大值）。**B 的削减主要发生在恢复段。**

### ② 扰动窗口放大
脉冲窗（112.0–113.5 s）内 A 与 B 几乎重合，B 的瞬时峰值还略高一点：
**A 0.361° / B 0.366°（+1.6 %）**。

这一条要说清楚：**CMG 的收益不是"顶住第一下"，而是"更快把扰动吃掉"。**
脉冲持续 1.5 s，CMG 在这个窗口内的出力只有约 0.66 N·m，
而气动在 100 km 处本来就有 11.3 N·m 的权限，第一下并不缺执行机构。
差别出现在 115 s 之后——见③。

### ③ 俯仰误差
115–130 s 的恢复段，B 明显低于 A（峰值区 A ≈ 0.82°，B ≈ 0.77°）。
这是 CMG 全程的主要贡献段：它把脉冲在机体上留下的角速度更快地拿掉。

### ④ CMG 动量
|H_cmg| 从 100 s 的 0.32 N·m·s 涨到 **120 s 的 5.77 N·m·s（全程峰值）**，
随后持续卸载，到 144 s 降到 1.40 N·m·s。

- 峰值仅为**硬预算 60 N·m·s 的 9.6 %**；
- 距单轴可用容量 **107.7 N·m·s**（±90° 行程）有 **18.7 倍余量**；
- σ_min 从初始 40.82 只降到 37.81，**离奇异裕度下限 12.25 很远**。

结论：**在这个算例里 CMG 完全没有被用满。**

### ⑤ CMG 出力
全程力矩峰值 **3.94 N·m（出现在 t = 100.4 s，爬升段）**，
脉冲窗内仅约 0.66 N·m。

- 3.94 N·m 只是**全向保证力矩 86.7 N·m 的 4.5 %**（相对保守下界 61.2 N·m 为 6.4 %）；
- 因此本图纵轴满量程只有 ±3.93 N·m，86.7 N·m 的参考线远在图外。

它的实际工作方式是"在 100–115 s 持续做小幅修正 + 脉冲后参与恢复"，而不是"瞬态猛出力"。

### ⑥ 舵面偏角
| | 升降舵峰值 |
|---|---|
| A | 14.63° |
| B | **13.77°**（−5.9 %） |

舵面最大权限是 25°，A 用掉 58.5 %，B 用掉 55.1 %。
**CMG 替舵面分担了一部分权限**——这是加 CMG 的直接工程收益。

## 4. 结论

**1. 在 100 km 顶点、120 N·m·s 脉冲下，加 CMG 是正的、一致的，但幅度不大。**
RMSE 降 4.2 %、峰值降 6.1 %、舵面峰值降 5.9 %。方向明确，量级温和。

**2. 幅度小的原因是物理，不是控制器没调好。**
100 km 处气动最大俯仰力矩 11.3 N·m，虽然只有脉冲幅值 80 N·m 的 14 %，
但对 120 N·m·s 的**总冲量**来说，气动只需约 120 / 11.3 ≈ **10.6 s** 就能把它吸收完，
而任务允许的恢复时间是几十秒。**气动在这个高度是够用的**，CMG 属于锦上添花。

**3. CMG 在这个算例里远未被用满**（动量 9.6 %、力矩 6.4 %、σ 几乎不动），
说明本算例根本没有触及它的能力边界。

**4. 这正好解释了为什么"把高度升上去"看似合理、实际适得其反。**
气动权限与 CMG 保证力矩的交叉点在 **89.4 km**：
- 低于此高度，气动能收尾，CMG 只需帮一点忙 → 本算例（100 km）的温和收益；
- 高于此高度，气动彻底失去收尾能力（115 km 只剩 **0.82 N·m**）。此时 CMG 是唯一有
  权限的执行机构，但它是**动量交换装置而不是动量汇**：顶点瞬态会在约 1 s 内耗尽
  可用动量，随后饱和，其自身反作用还会在无阻尼轴上留下残余角速度，
  **结果比不用更差**（115 km 实测：A RMSE 2.077° / B 4.018°）。

**5. 工程含义。**
CMG 的价值不是"任何工况都更好"，而是
**"在气动权限不足、同时存在动量卸载出路的区间内更好"**。
本算例所处的 100 km 位于这个窗口的内侧边缘，所以收益温和；
**89–100 km 是 CMG 价值最高的窗口**。要进一步放大它的作用，正确的方向不是继续升高高度，
而是加动量汇（RCS）把窗口向上打开。

## 5. 局限与如实说明

1. **瞬时峰值 B 略差（+1.6 %）**。整体优势全部来自 115 s 之后的恢复段，报告不回避这一点。
2. **CMG 动量未卸载到零**：145 s 时仍残留 1.40 N·m·s。动量管理器的卸载速率偏慢，
   长时运行会持续积累，需要调 `w_H` / 卸载增益。
3. 气动系数仍为线性示例值（`Cl_beta`、`Cm_alpha`、`Cn_beta` 等），需接入真实气动表后复算。
4. A / B 各有 8 / 5 次 MPC 回退（占 725 步的 1.1 % / 0.7 %），已由保底控制器兜住，
   未影响本报告结论。
5. 本图由脚本重新生成。此前版本的图注是手工写死的数字，已与数据脱节
   （例如标注的扰动量与实际不符），因此本报告中所有数字均以 CSV 为准。
